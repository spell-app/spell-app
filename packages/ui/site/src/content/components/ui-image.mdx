<Section title="Behaviour">
  `<ui-image>` renders a real `<img>`, so `src`, `alt`, `width`, `height` and `loading` work as they do on the native
  element.  `width` and `height` are the image's own pixel size, which reserves space before it loads;  `size` sets
  how wide it is drawn.  An image is a block on its own line;  `avatar`, `inline`, `spaced` and `vertical-align` make it
  sit in a line of text instead.

  `<ui-images>` shares its size, shape, border and alignment with every image inside it, plain `<img>`s included.
  Images have no events.

  <VocabularyTable family="ui-image" />
</Section>

<Section title="Theming">
  Theme with the public `--ui-image-*` tokens:  set one on the element, on any ancestor (a `<ui-images>` group, a
  region, `:root`), or on the inner box through `::part(image)` (`::part(group)` for `<ui-images>`).  They inherit
  into the shadow root, where the sheet reads each through a private alias, so nothing inside blocks them.  The
  group's own `--_ui-images-*` tokens are private.

```css
/* every image on the page */
:root {
  --ui-image-rounded-radius: 1em;
}
/* one gallery */
.gallery {
  --ui-image-border: 2px solid var(--ui-border-color-strong);
}
```

</Section>

<Section title="Accessibility">
  - Give every image an `alt`.  `alt=""` marks it decorative, so screen readers skip it;  a missing `alt` stays
    missing, and accessibility checkers will flag it.
  - A linked image (`href`) is a real link, named by its `alt`:  describe where it goes.
  - `disabled` removes the link's `href` and sets `aria-disabled`, so it is no longer focusable.
  - `<ui-images>` is a plain box with no role;  wrap it in a list or give it a label if the group means something.
  - Without JavaScript the native fallback renders the same `<img>` (or link around it) with the same class words, so
    the image, its `alt` and the group layout stay.
</Section>
