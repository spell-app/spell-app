  • OutputRoot is the pane: an OutputToolbar (just its "Javascript Output" header today) above an OutputEditor.
  • OutputEditor is a read-only MonacoEditor, coloured as javascript, showing the open file's compiled code. Monaco loads the first time it's needed.
  • It doesn't follow the cursor in the code pane.
  • An error drawing it shows in its place, and goes to showError.
