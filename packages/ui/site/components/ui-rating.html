Rating A rating indicates user interest in content. Types

















You can use decimal values for showing partially filled ratings.

A fractional value only draws a partly filled icon: no radio is chosen until the user rates, and the group is described as "Rated 2.5 of 5". Fomantic's jQuery and browser caveats don't apply: every supported browser draws it.
