<epic-prompt> is the prompt that started the plan, as Owen typed it. It draws a fold titled "Kickoff prompt" on ivory, Owen's colour; unfolded, the prompt shows as a quoted card.

Written for: anyone reading or writing a plan doc's markup, or changing this element.
Status: built in epic-prompt/.
Its vocabulary (attributes, slots, parts, children): EpicPrompt.en.ts.
The component: EpicPrompt.tsx.

Plan docs (epic pages) as Solid web components, instead of HTML that carries its own layout:

Pieces of what it draws, which a page's CSS can style from outside with ::part(name).

Part What it is
base The fold: a <details>, folded to start with.
title Its <summary>: the chevron and Kickoff prompt.
quote The card around the prompt, shown unfolded.
  • Folded (as it starts): a chevron and "Kickoff prompt", in italic serif, on the brand's ivory: Owen's voice in the colour scheme.
  • Unfolded: the chevron turns down, and the prompt shows as a white card with a thin rule, on the ivory.
  • Whether it's open is the reader's, never written in the file. Find-in-page unfolds it.
  • spell dev plan-doc new <name> --prompt "..." or --prompt-file <path>: the prompt, as the doc is made.
  • spell dev plan-doc prompt <name> "..." or --file <path>: sets or replaces it; "" removes it. On an older doc it turns the old quote into an <epic-prompt> where it stood.
  • spell dev plan-doc convert's second pass: an older doc's <blockquote slot="prompt"> became one.
