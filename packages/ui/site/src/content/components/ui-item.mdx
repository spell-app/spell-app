<Section title="Behaviour">
  Fomantic shares one `.item` between dropdowns, lists and menus, and so does this library:  there is one `<ui-item>`,
  never a `ui-list-item` or `ui-menu-item`.  The item looks at what holds it and renders to match:

  - In a [dropdown](../ui-dropdown/) it is data.  It renders only its content, and the dropdown draws the option rows
    (rich markup inside an item is shown in its row).
  - In a [list](../ui-list/) it is a list row;  in a [menu](../ui-menu/) it is a menu item.  The box is a link with `href`, a
    button with `link` or when the owner makes its items interactive, otherwise a plain block that can hold text,
    inputs, buttons or a dropdown.
  - Anywhere else it renders just its content.

  `selected` is the canonical attribute for the chosen item;  `active`, Fomantic's word, is accepted as an alias in
  lists and menus.  An item fires no events of its own:  its list or menu fires `ui-select` when a link or button item
  is activated (`detail.item` is the `<ui-item>`), and a dropdown fires `ui-change`.  Attributes marked "Dropdown",
  "List" or "Menu" below are read only by that owner.

</Section>

<Section title="Theming">
  An item has no tokens of its own:  its look comes from its owner, so theme it through the
  [list](../ui-list/#theming) or [menu](../ui-menu/#theming) tokens.  Style the pieces of a list or menu item with
  `::part()`:  `item` (the box), `icon` and `image`.

```css
ui-menu ui-item::part(item) {
  font-weight: bold;
}
ui-list ui-item::part(image) {
  border-radius: 0.25em;
}
```

</Section>

<Section title="Accessibility">
  - In a list the item is a `listitem`;  in an `interactive` menu its box is a `menuitem` and the item itself has
    `role="none"`;  in a navigation menu it adds no role, so its link or button speaks for itself.
  - A link or button box is a real `<a href>` or `<button>`, so focus, Enter, Space and the accessible name come from
    the browser.  An icon-only item needs a name:  put `aria-label` on the `<ui-item>` and it moves to the box.
  - A selected item is `aria-current="page"` when it is a link, `aria-current="true"` otherwise.
  - `disabled` removes a link's `href` (and sets `aria-disabled`), or disables a button.
  - The `image` shorthand is decorative (`alt=""`);  a `divider` is a `role="separator"`.
  - In a dropdown the dropdown owns the semantics:  items become `option`s of its listbox (see
    [Dropdown](../ui-dropdown/#accessibility)).
  - If the item can't render, its native fallback keeps the list or menu box and class words:  links stay links.  It
    drops the `icon` and `image` shorthands, button items (a plain block unless `href`), `menuitem` roles and the
    `aria-current` of non-link items.
</Section>
