<Section title="Behaviour">
  An ELEMENT dimmer (the default) covers its parent:  the nearest positioned box, and the page stylesheet positions
  a plain parent for it.  Like Fomantic's, it is not modal:  what it covers stays in the page.  A PAGE dimmer
  (`page`) is a `<dialog>` shown with `showModal()`, and it IS modal:  it covers everything, so the page behind it
  is inert (no Tab, no screen reader), focus moves inside and comes back when it hides, the page can't scroll, and
  Escape closes it.

  `active` is the controlled state:  writing it shows or hides the dimmer and fires nothing.  User actions (the
  `on` trigger, a click, Escape, an invoker command) dispatch the cancelable `ui-open` / `ui-close` first
  (`detail.reason` is `click`, `escape`, `hover` or `close-all`), then `ui-show` / `ui-hide` after the fade.
  `closedby` says what hides it, as on `<dialog closedby>`:  `any` (the default:  a click on the dimmer, not its
  content, and Escape on a page dimmer), `closerequest` (Escape only) or `none` (only `active`).  A hover dimmer
  ignores clicks.  Native buttons drive it with no script:  `command="--show"`, `--close` or `--toggle`.

```js
const busy = document.querySelector("#busy") // <ui-dimmer id="busy" page closedby="none" aria-label="Saving">
busy.active = true // show from code:  no event
await save()
busy.active = false
```

<Section title="Theming">
Theme with the public `--ui-dimmer-*` tokens:  set one on the element, on any ancestor (`:root` for every dimmer), or
  on the box through `::part(dimmer)`.  `--ui-dimmer-background`, `-inverted-background`,
  `-blurred-background`, `-blur` and `-duration` are read where they paint.  They're SHARED:
  `--ui-dimmer-background` also colours `<ui-modal>`'s backdrop, and `<ui-flyout blurring>` and
  `<ui-sidebar blurring>` read the blur tokens, so one rule on `:root` themes every dimmer on the page.  The shades
  (`medium`, `light`, `very light`) set their own background.  Style the centred box with `::part(content)`.

```css
:root {
  --ui-dimmer-background: oklch(0.2 0.05 260 / 0.8);
  --ui-dimmer-blur: blur(8px);
}
ui-dimmer::part(content) {
  max-width: 30em;
}
```

<Section title="Accessibility">
  - A page dimmer is modal:  a `<dialog>` in the top layer, the rest of the page inert, focus inside (on the dialog
    itself when nothing inside can take focus) and back where it was when it hides.  Name it with `aria-label`;
    otherwise it is "Dimmed page" (translated).
  - An element dimmer is NOT modal:  what it covers can still be reached with Tab and read.  If it means "busy",
    mark the covered region `aria-busy` or `inert` yourself.
  - A hover dimmer also shows on keyboard focus inside its parent, and stays laid out (transparent) while hidden, so
    Tab reaches its buttons.  Fomantic's was mouse-only.
  - Escape closes a page dimmer unless `closedby="none"`;  with `none`, hide it from code.

  | Key       | Action                                                         |
  | --------- | -------------------------------------------------------------- |
  | Tab       | Moves focus inside a page dimmer only (the page behind is inert) |
  | Escape    | Closes a page dimmer (`closedby` `any` or `closerequest`)       |

  - If the element can't render, its native fallback still follows `active`, and a page dimmer is still a native
    modal `<dialog>` that covers, blocks and closes on Escape.  `on` triggers, the `ui-open` / `ui-close` vetoes and
    the fade are lost.
</Section>

<Section title="Framework usage">
  Bind `active` to your state and listen for `ui-close` to follow the user.

```jsx
// React 19
<ui-dimmer page active={busy} aria-label="Saving" onui-close={() => setBusy(false)}>...</ui-dimmer>
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-dimmer page :active="busy" aria-label="Saving" @ui-close="busy = false">...</ui-dimmer>
```

```jsx
// Solid 2:  no `on:` namespace -- listen through a ref
<ui-dimmer page prop:active={busy()} aria-label="Saving" ref={(el) => el.addEventListener("ui-close", () => setBusy(false))}>
  ...
</ui-dimmer>
```

</Section>
