<spell-code> A block of spell, coloured by spell's own parser.

A <ui-code> whose language is spell unless it says otherwise. Loading it registers spell with the page's Spell UI, so every <ui-code language="spell"> on the page is coloured too, and every spell block of a markdown.

Written for: anyone showing spell in a page, or changing how spell is coloured Live: the real element, from the app's element build this page loads

A snippet, and the same in a plain <ui-code language="spell"> beside it.

a card is a drawable thing

Live, from /element/spell.pack.js (yarn build:element in spell-app), which this set's pages load.

  • Everything <ui-code> takes: inline text or a source file, line-numbers, wrap, copy, another language.
  • spell/<lang> asks for a translation; one that doesn't exist stays plain, with a ui-error.
  • The colours come from spell's own parser, a lazy chunk fetched the first time a page shows spell.
  • Spell UI itself knows nothing of spell: this is one more language a page registers with UI.code.register().
  • The docs pages (epic pages, guides) colour spell without it: the page server adds the app's spell-language.js to them, which registers the language and defines no element.
