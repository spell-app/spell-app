<Section title="Behaviour">
  `country` takes:

  - any two-letter country code ([the ISO 3166-1 alpha-2 list](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#Officially_assigned_code_elements)),
    in any case:  `fr`, `US`;
  - or the English names and aliases from [Fomantic's flag list](https://fomantic-ui.com/elements/flag.html):
    `france`, `united states`, `america`, `uk`, `czech republic` ...  Underscores count as spaces, so
    `United_States` works too;
  - or one of the non-country flags above.

  The flag is the Unicode flag emoji, drawn by the platform's emoji font:  no images to download and no CSS per
  country.  An unknown `country` renders an empty box of the same size, so the line doesn't jump.  Flags have no
  events.

</Section>

<Section title="Theming">
  Theme with the public `--ui-flag-*` tokens:  set one on the element, on any ancestor (a region, `:root`), or on the
  flag's box through `::part(flag)`.  They inherit into the shadow root, where the sheet reads each through a private
  alias, so nothing inside blocks them.  Windows' emoji font has no flags and shows the two letters instead;  to get
  real flags there, load a flag font (for example the "Twemoji Country Flags" polyfill) and name it first in
  `--ui-flag-font-family`, once for the page.

```css
:root {
  --ui-flag-font-family: "Twemoji Country Flags", "Apple Color Emoji", "Segoe UI Emoji", "Noto Color Emoji", sans-serif;
}
```

</Section>

<Section title="Accessibility">
  - A flag is an image named after its country (`role="img"`, `aria-label="France"`).  The name comes from the
    browser's own list of region names in the page's language, so it is translated for free.
  - The non-country flags have their own names ("Rainbow flag", "Pirate flag", "England" ...), which a translation
    can change.
  - A flag with an unknown `country` has no role and no name, so screen readers skip it.
  - Without JavaScript the native fallback draws the same emoji with the same name in the page's language;  only the
    names of the non-country flags stay in English.
</Section>
