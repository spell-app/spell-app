<epic-commit> The <epic-commit> element: one commit that built a phase or fixed an item, its short sha linked.

One commit that built a phase or fixed an item.

  • It draws the commit's short sha (its first 7 characters), linked to GitHub, then the doc's sentence about it.
  • The first of a run also draws a "Commits:" heading.

For anyone reading or writing a plan doc's markup, or changing this element.
Its vocabulary (every name it uses): EpicCommit.en.ts.
Its component: EpicCommit.tsx, with its style sheet (.css) and tests beside it.

Its parents:

  • <epic-phase>: its commits, oldest first, after Done (else Goal) and before Files
  • <epic-item>: the commits that fixed or built it, oldest first, last in the item

Its children:

  • prose: what it did, one or two sentences

Its link comes from the nearest <epic-page repo>: <repo>/commit/<sha>, opening in one shared GitHub tab.

A slot is where the element's own children show.

Slot Holds
(default) What it did, one or two sentences.

A part is a piece of the drawing a page's CSS can reach.

Part Is
base The commit: its heading (the first of a run only), then its line.
heading Commits: with its icon, over the first of a run of commits.
sha The short sha: a link when the page has a repo.
  • Hidden until shown: the page header's git toggle shows every commit, an item's git icon its own. Both set --epic-commits-display.
  • The sha: a small chip on the code-well background, in mono, the link colour. Without a repo it's plain code, in the text's ink.
  • The first of a run carries Commits: and a code-branch icon; the lines sit under the heading's text.
  • No state colour, and it doesn't fold.
  • spell dev plan-doc commit <name> <sha> --phase N | --item <id> "<sentence>": lists one, replacing the entry already there for that sha.
  • spell dev plan-doc commits <name> --backfill: every phase and item commit in the doc's git history not listed yet, read from subjects (P3: Name -- summary, Fix I3: ...).
  • Both write <epic-page repo> from the checkout's origin remote, when it's on GitHub.
  • The converter turned the old phase and item commit lists into it (CardConverter, PhaseConverter).
