SpellElement A view, drawn as an element of its own, one tag per template.

A spell template declared as a card is a view draws each of its things as its own element, with its own shadow root, styles and error boundary. Its properties are the element's attributes, and its actions the element's methods, so a page's own markup and script can use it too.

Written for: anyone writing a view in spell, or changing how programs draw Live: a real program's elements, in a <spell-viewer> this page loads

Solitaire, drawn with views: each card is its own <solitaire-card> element, and each pile, e.g. a <solitaire-tableau>, holds its cards' elements.

  • ONE tag per view template, named for its app and template, and defined the first time a program defines its elements. A program run again takes the tag over, and restyles every element of it at once.
  • draw the card draws the card's element, with the card as its thing. The element draws the card inside its shadow root.
  • Each property the type declares is an attribute and a property: rank="queen", or card.rank = "jack". Each action is a method: card.turnOver().
  • Written by hand, with no thing, it makes its own: a new thing of its type.
  • In a <spell-viewer>'s own markup, it draws the program's thing of its type named by its id, or says there's none.
  • Its styles: the page's theme, then its type's <css>, after its super-types'.

The attributes every view's element starts with. Each template adds one per property it declares: a card's rank, suit and direction.
