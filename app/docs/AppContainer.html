Only AppRoot draws one, and hands its box to the editor:

AppRoot.tsx · the program's box · 8 lines
  • appRef is told which element the program draws in, once it's on the page.
  • The program draws with its own Solid root on that element, when it starts: the app's Solid draws the element once and leaves what's inside alone.
  • The element's id is spell-app-root: where a program draws when no one has said where. The id is written out, not imported, because the app must never load the program's runtime itself.
  • It imports nothing from the app's other components, so a runner could use it without pulling in the editor. The VS Code runner draws a box with the same class and look, but not this component.
