<spell-editor> Edits a spell project in any page, and runs it in the apps beside it.

One tag puts the spell app's code editor in a page: a tab per file, Monaco, and a status line. It compiles as you type, and hands what it compiled to the <spell-viewer> elements beside it, which run it at once.

Written for: anyone putting an editable spell program in a page, or changing the editor Live: the real element, from the app's element build this page loads

The calculator example's code, beside the calculator it runs.

Look, but don't edit. Typing here SAVES to the repo's Calculator example: every compile saves the files edited since, and so does Cmd+S.

Live, from the app's element build, which this set's pages load: /element/spell.pack.js. The app package builds it with yarn build:element.

Link an editor to its apps from either side: the editor's app names them, or each app's editor names it. As the editor's demo page does:

spell-editor.html · linked from the editor's side · 4 lines spell-editor.html · linked from the apps' side · 5 lines
  • What it edits: project, from the spell server, as <spell-viewer> takes it. file picks the file shown first; tabs show the others.
  • Edits SAVE back to the project: every compile saves the files edited since, and Cmd+S saves.
  • It compiles as it opens the project, 2 seconds after typing stops, and at once on Cmd+Enter.
  • After each compile with no parse errors, it sends spell-compiled, and each linked app runs what it made. An app added later gets its next compile.
  • It compiles before Monaco loads, so its apps run straight away. Monaco, most of its code, comes after.
  • Several on a page edit several projects. Two of one project share its files: typing in one shows in the other.
  • Its script API: compile() and save(). Its compiled holds what it last compiled.
  • A page loads it as it loads <spell-viewer>: by itself, or by the element pack.
