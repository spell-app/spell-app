<Section title="Behaviour">
  Scripts in the included markup never run.  `ui-*` tags in it load their families on demand, as `<ui-root>` does.
  Relative `href` / `src` / `source` are rewritten against the included page's URL, so its links, images and nested
  includes still point where they did;  an include inside an include of the same page shows an error.

  For editors:  `contentRoot` is where the markup lives.  Edit it in place, then `save()`:  `content` is the file
  with the live markup spliced into its `<body>` (byte-exact outside it), or, with `select`, the matched element
  alone, saved by its `id`.  Saving goes through `UI.sources.saver`, which the page registers (`ui` ships none);  the
  cancelable `ui-save` lets an editor save it elsewhere.
</Section>
