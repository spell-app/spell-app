There is a list of habits. People can add a habit by typing its name. Tapping a habit marks it done. A streak is the number of days in a row a habit was done.

Compiled
habits = list({ name, done })
add(name) → habits.push(…)
toggle(h) → h.done = !h.done
streak = days.takeWhile(
  d → d.every(done))
