<spell-markdown> Markdown drawn by spell's own engine, in ui-* elements.

A <ui-markdown> drawn by spell's markdown engine instead of marked: headers, lists, tables, alerts and tasks as Spell UI's own elements, plain or editable. Its spell blocks are coloured by spell's parser.

Written for: anyone showing markdown with spell in it, or changing spell's markdown engine Live: the real element, from the app's element build this page loads

Live, from /element/spell.pack.js (yarn build:element in packages/app), which this set's pages load.

  • Everything <ui-markdown> takes: inline text or a source file, sanitized (which keeps its ui-* elements), heading-offset, skip-title, headings and reveal().
  • Its engine is spell's (@spell-app/markdown, on the parser), a lazy chunk loaded with the first render.
  • It loads <spell-code> too, so a spell code block is coloured.
  • Compiled spell's own <markdown> blocks still draw with <ui-markdown>.

From its vocabulary, by yarn site:data in packages/app.

  • SpellMarkdown.en.ts: what its vocabulary adds to <ui-markdown>'s
  • MDEngine.ts: spell's markdown engine, as <ui-markdown> asks for one
  • Its build: yarn build:element, into dist-element/, served at /element/
