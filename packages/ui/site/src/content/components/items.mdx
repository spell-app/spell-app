<Section title="Behaviour">
  An item here is the same `<ui-item>` that [dropdowns](../dropdown/), [lists](../list/) and [menus](../menu/) use
  (see [item](../item/)):  there is no separate "items item".  Inside `<ui-items>` it becomes a block with its image
  on one side and a `<ui-content>` on the other, and it styles the [content parts](../parts/) inside it
  (`<ui-header>`, `<ui-meta>`, `<ui-description>`, `<ui-extra>`) as Fomantic's item header, meta and so on.  The same
  parts inside a list item still look like list parts.

  - The image:  the `image` shorthand, a slotted `<img>` (the item's image width), or a `<ui-image size>` (its own
    size).
  - `href` makes the whole item one link;  `link` on the group is only the hover look.
  - Items stack, image above content, when the GROUP is narrower than 768px, whatever the window's width;
    `unstackable` keeps them side by side.
  - A group has no events;  a link item is a normal link.

</Section>

<Section title="Theming">
  Theme with the public `--ui-items-*` tokens:  set one on the element, on any ancestor (a region, `:root`), or on the
  group's box through `::part(items)`.  The items inside read them from the group, so set them there or above, not on
  one item.

```css
ui-items {
  --ui-items-image-width: 8em;
  --ui-items-divided-border: 2px solid var(--ui-border-color);
}
```

</Section>

<Section title="Accessibility">
  - The group is a `role="list"` and each item a `listitem`, so a screen reader hears how many there are.
  - A link item is one `<a>` whose name is all of its text.  Keep other links and buttons out of it, and don't give a
    linked header its own `href` inside one.
  - Give a `<ui-header>` a `level` when an item's title should be a heading in the page outline.
  - A slotted image needs its own `alt`;  the `image` shorthand is decorative (`alt=""`), so put what matters in
    the text.
  - `disabled` fades the item and sets `aria-disabled`.
  - If the element can't render, its native fallback keeps the list and class words, so the items still read as a
    list;  they no longer stack in a narrow group, and their headers, metas and descriptions lose the item look.
</Section>
