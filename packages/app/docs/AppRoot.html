AppRoot The running program in the editor's pages, under its toolbar.

The pane where the program you're editing runs, on the editor and runner pages. It's a toolbar to restart the program, over the box the program draws in, and it tells the editor where that box is.

Written for: anyone changing the spell app's editor, or how it runs programs A picture, not live: the editor's App pane, with Solitaire running in it

The editor's App pane: the purple toolbar is its AppToolbar, and under it, the program draws in an AppContainer.

A picture, taken by yarn site:pictures in packages/app.

The editor page puts it at the top of its right-hand column; the runner page, with no toolbar:

SpellEditor.tsx · the editor's right-hand column · 5 lines SpellRunner.tsx · the run page · 4 lines
  • Once drawn, it hands its box to the editor with editor.setAppRoot(): that's where the editor runs programs from then on.
  • When it goes, it takes the box back with editor.releaseAppRoot(), but only if it's still the editor's: moving from the editor page to the runner page, the new page's AppRoot may hand its box over first.
  • <AppToolbar>, above it: an "App" header, then Restart and Publish (the app's Actions), and a "..." menu that isn't built yet.
  • The program's box scrolls and is padded, unless told not to.
  • A live <spell-app> doesn't use it: the runner has its own panes.
