Actions The editor's actions, each as a menu item or a button.

Everything a person can tell the editor to do from a toolbar or a menu: Save, New File, Restart, Settings. Each one is ready to drop into a bar, a "..." menu, or a page as a button, with its own text, icon and click.

Written for: anyone adding a button or menu item to the spell app A picture, not live: they act on the editor, so they need it running

The input editor's toolbar: Save, Reload and New File are actions, drawn as icons, each naming itself in a tooltip. Save lights up while the file has unsaved changes.

  • <Action> is one action: a menu item by default, or a button with button.
    • title: its text
    • icon: its icon
    • iconOnly: just its icon, its title a tooltip below it after two seconds
    • active: lights it up
  • Actions holds the app's own, each an Action with its text, icon and click filled in, in groups:
    • going places: Edit, Run, Settings, Home, Help, and You, the person's avatar
    • the project: create, duplicate, rename, delete it; its settings; restart it, or reset an example
    • files: create, duplicate, rename, delete, save, reload
    • the console: Clear Console
    • dialogs, for trying them out: alert, confirm, prompt, a number prompt, and choose
  • Props given where it's drawn win over the entry's own: its text, its icon, its click handler (onClick) ...
  • Some light up as the editor changes: Save and Reload when the file has unsaved changes.
  • PROJECT_DROPDOWN_ACTIONS and FILE_DROPDOWN_ACTIONS are the four create / duplicate / rename / delete actions, for the "..." menus in Chrome.
  • In a "..." menu, keep title plain text: the menu draws its items from their text.
