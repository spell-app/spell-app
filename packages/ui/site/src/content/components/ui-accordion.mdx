<Section title="Behaviour">
  Children come in PAIRS, like Fomantic's `.title` + `.content`:  each `<ui-title>` starts a panel and the element
  right after it is the panel's content.  There is no panel element to write.  In its shadow root the accordion
  wraps each pair in a native `<details>`, with the title in its `<summary>`, so the browser does the disclosure:
  the title is a real button, Enter and Space toggle it, and find-in-page opens the panel that holds a match.
  An `exclusive` accordion (the default) is one `<details name>` group, so opening a panel closes the others.

  `open` lists the open panels by index, from 0 and space-separated (`open="0 2"`);  while `exclusive`, only the
  first index counts.  Writing `open` opens and closes panels and fires nothing.  When the user activates a title,
  the cancelable `ui-open` / `ui-close` go first (with `{ index, open, title, content }`);  switching panels in an
  exclusive accordion announces the close too.  `preventDefault()` keeps things as they were.

```js
const faq = document.querySelector("ui-accordion")
faq.addEventListener("ui-open", (event) => {
  if (event.detail.index === 2 && !signedIn) event.preventDefault() // stays closed
})
faq.open = "0 1" // open panels from code:  no event
```

  Panels open and close with a height transition where the browser can animate to `auto` (`interpolate-size`);
  with reduced motion they snap.

<Section title="Theming">
Theme with the public `--ui-accordion-*` tokens:  set one on the element, on any ancestor (`:root` for every accordion), or
  on the box through `::part(accordion)`.  `styled`, `compact` and `basic` replace
  the paddings and colours whatever you set.  Open and hovered title colours follow `--ui-accordion-title-color`
  unless set.  A nested accordion takes the outermost one's look, so theme the outer one.  Style the pieces with
  `::part()`:  `panel` (each `<details>`), `title`, `icon` (the arrow) and `content`.

```css
ui-accordion {
  --ui-accordion-title-padding: 0.75em 0;
  --ui-accordion-duration: 0.2s;
}
ui-accordion::part(title) {
  text-transform: uppercase;
}
```

<Section title="Accessibility">
  - Each title is a native `<summary>`:  a focusable button that exposes whether its panel is expanded, with no ARIA
    to keep in sync.
  - Arrow keys move between the titles of one accordion, as the APG accordion pattern suggests.
  - Find-in-page (Ctrl / Cmd + F) opens a closed panel that holds a match.  That opening can't be vetoed:
    `ui-open` still fires, but `preventDefault()` does nothing.
  - Titles are buttons, not headings:  they don't appear in the page's outline.

  | Key                   | Action                                              |
  | --------------------- | --------------------------------------------------- |
  | Tab / Shift + Tab     | Move to the next / previous title (and into an open panel) |
  | Enter / Space         | Open or close the focused panel                     |
  | Arrow Down / Arrow Up | Move to the next / previous title                   |
  | Home / End            | Move to the first / last title                      |

  - If the element can't render, its native fallback is the same `<details>` panels, which keep working on their
    own:  titles still toggle, an exclusive group still closes the others.  `ui-open` / `ui-close`, the arrow keys
    between titles and the animation are lost.
</Section>

<Section title="Framework usage">
  Bind `open` (a string of indexes) and listen for `ui-open` / `ui-close` to follow the user.

```jsx
// React 19
<ui-accordion styled open={String(index)} onui-open={(e) => setIndex(e.detail.index)}>...</ui-accordion>
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-accordion styled :open="String(index)" @ui-open="(e) => (index = e.detail.index)">...</ui-accordion>
```

```jsx
// Solid 2:  no `on:` namespace -- listen through a ref
<ui-accordion styled open={String(index())} ref={(el) => el.addEventListener("ui-open", (e) => setIndex(e.detail.index))}>
  ...
</ui-accordion>
```

</Section>
