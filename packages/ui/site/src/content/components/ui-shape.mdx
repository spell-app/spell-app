<Section title="Behaviour">
  A shape's children are its sides:  one `<ui-side>` per face, in order, as Fomantic's markup has a `.side` per face.
  `active-index` (from 0) is the side shown.  Changing it turns the shape the `direction` way (`up`, `down`, `left`,
  `right`, `over`, `back`) to that side.  The attribute is `direction`, not `flip`:  `flip()` is a method.

  The host has Fomantic's behaviours as methods, each resolving once the turn has finished:  `flip(direction?,
  index?)`, `next()` and `previous()` (both wrap round).  Each writes `activeIndex`, so it reflects.  Invoker commands
  do the same with no script:  `--next` and `--previous`.  Flips queue, as Fomantic's did, and `ui-change` fires once
  another side is shown, with `{ activeIndex, side, flip }`.

```js
const dice = document.querySelector("#dice")
await dice.next() // the next side, the `direction` way
await dice.flip("back", 0) // back to the first side
dice.addEventListener("ui-change", (event) => console.log(event.detail.activeIndex))
```

  The turn is Fomantic's own geometry, as a CSS transition;  under reduced motion the sides swap at once.

<Section title="Theming">
  Theme with the public `--ui-shape-*` token on the shape or any ancestor;  `::part(shape)` works too.  Style the
  pieces with `::part()`:  `shape` (the stage, with the 3D perspective) and `sides` (the box that turns) on the
  shape, `side` (the face) on each `<ui-side>`.

```css
ui-shape[cube] {
  --ui-shape-cube-size: 10em;
}
ui-side::part(side) {
  border-radius: 0.5em;
}
```

<Section title="Accessibility">
  - Only the side shown is in the accessibility tree;  the others are hidden.
  - The box that turns is a polite live region, so the new side is read out after a flip.
  - A shape has no keyboard of its own:  turn it from real buttons (`commandfor`), so everyone can.
  - If the element can't render, its native fallback shows every side, stacked:  no flips, invoker commands or
    `ui-change`, and the methods resolve `false`.
</Section>

<Section title="Framework usage">
  Bind `active-index` and listen for `ui-change`, or call the methods through a ref.

```jsx
// React 19
<ui-shape cube active-index={side} onui-change={(e) => setSide(e.detail.activeIndex)}>...</ui-shape>
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-shape cube :active-index="side" @ui-change="(e) => (side = e.detail.activeIndex)">...</ui-shape>
```

```jsx
// Solid 2:  no `on:` namespace -- listen through a ref
<ui-shape cube active-index={side()} ref={(el) => el.addEventListener("ui-change", (e) => setSide(e.detail.activeIndex))}>
  ...
</ui-shape>
```

</Section>
