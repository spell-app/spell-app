Search A search module allows a user to query for results from a selection of data. Every <ui-search> is drawn as Fomantic's ui icon input, so the icon input needs no extra markup. The icon slot swaps the magnifying glass.

A search can show a remove icon to be able to cancel a previous search term.

Not yet: there is no remove icon. Escape closes the results, and a second Escape clears the text.

A search can look for results inside a static local source.

Results that begin with the query come first, then content that matches the query anywhere inside. To match word starts only, set full-text-search="prefix" (Fomantic's fullTextSearch: false).

A search can have its results scroll.

The scroll height depends on the viewport: 4 results' height, 6 / 8 / 12 from 768px / 992px / 1920px. --ui-search-results-max-height replaces it at every width. Add resizable to scrolling and a native resize handle appears at the bottom right of the results.

A search can be very-short (0.75x of the default height) so that more results can be glanced, or short, long (2x) and very-long.

The default height is the height of one result times the number of results shown at the current breakpoint.
