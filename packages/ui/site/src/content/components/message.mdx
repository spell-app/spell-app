<Section title="Behaviour">
  The content is whatever you slot:  paragraphs, a list, a `<ui-header>`.  A `dismissible` message fires the cancelable
  `ui-dismiss` when its close button is used;  unless a handler cancels it, the message sets `hidden` on itself.  It
  never removes itself, so a framework that rendered it still owns the node.  Remove `hidden` to show it again.

  Inside a `<ui-form>`, a message with a `state` shows only while the form is in that state (see the Form page).

```js
const message = document.querySelector("ui-message[dismissible]")
message.addEventListener("ui-dismiss", (event) => {
  event.preventDefault() // keep it on screen
  message.remove() // ... or take it out yourself
})
```

<Section title="Theming">
  Theme with the public `--ui-message-*` tokens:  set one on the element, on any ancestor (`:root` for every
  message), or on the box through `::part(message)`.  They inherit into the shadow root, where the sheet reads each
  through a private alias, so nothing inside blocks them.  A slotted header reads `--ui-message-header-font-size`
  from the message.  Style the other pieces with `::part()`:  `icon`, `content`, `header` and `close`.

```css
:root {
  --ui-message-radius: 0;
}
ui-message.notice {
  --ui-message-padding: 1.5em 2em;
}
ui-message::part(close) {
  opacity: 1;
}
```

<Section title="Accessibility">
  - A message has no role of its own, because most messages are part of the page.  A message you insert to announce
    something should carry `role="status"` (or `role="alert"` when it is urgent), set by the page.
  - The close button of a `dismissible` message is a real `<button>` named "Dismiss" (translatable), and a tab stop.
  - The icon is decoration:  it is hidden from assistive technology, so say what it means in the text.
  - A `state` or `color` is never the only signal:  write the meaning in the header or text as well.
  - Without JavaScript the native fallback renders the same markup with a working close button (it still fires
    `ui-dismiss` and hides the message).  It drops the `icon` glyph (a slotted icon still shows) and the close
    button's glyph, which becomes a `×`, and the "Dismiss" name stays English.
</Section>

<Section title="Framework usage">
  Listen for `ui-dismiss`, and cancel it when your framework should decide whether the message stays.

```jsx
// React 19
{shown && <ui-message dismissible header="Saved" onui-dismiss={(e) => { e.preventDefault(); setShown(false) }} />}
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-message v-if="shown" dismissible header="Saved" @ui-dismiss.prevent="shown = false" />
```

```jsx
// Solid 2:  no `on:` namespace, so listen from a ref callback
<Show when={shown()}>
  <ui-message
    dismissible
    header="Saved"
    ref={(el) => el.addEventListener("ui-dismiss", (e) => { e.preventDefault(); setShown(false) })}
  />
</Show>
```

</Section>
