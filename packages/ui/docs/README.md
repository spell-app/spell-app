# Design docs

Design documents for `@spell/ui` live here, next to the code they describe.

- `plan.md` -- the approved plan (2026-09-28):  decisions, architecture, CSS system, component runtime,
  milestones, definition of done.  Start here.
- `report.md` -- the status report:  bundle tiers, LOC, perf, framework hosts, HMR, fallbacks;  its tables are
  generated by `yarn report`.
- `spike-lit-vs-solid.md` -- the Milestone 0 result (Solid 2);  `plan-promote-solid.md` -- moving the Solid spike
  into the package.
- `grammar.md` (attribute kinds -> Fomantic classes), `theming.md` (tokens, layers, `#ui-app-stylesheet`),
  `translation.md` (vocabulary / translated names contract), `icons.md`, `fallback.md`, `runtime.md`.
