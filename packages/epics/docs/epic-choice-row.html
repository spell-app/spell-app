A part is a piece of what the element draws in its shadow root (its own hidden markup), named so a stylesheet can reach it: epic-choice-row::part(base).

Part What it is
base Its cells, laid out on its table's columns.
order The Order cell, in a table Owen puts in order: its place, and its move up / move down buttons.
up The move up button: it swaps places with the row above.
down The move down button: it swaps places with the row below.
file The File cell: the file's name and line, a link into VS Code; its folder under it.
purpose The Purpose cell: the purpose, stays when it stays, the note.
current The Current cell: today's text, as code.
pick The Recommended cell: the box, and the reset button once it differs.
box The <textarea>: one line of text, wrapping and growing; Enter adds no line.
reset The round button putting the recommendation back.

A state is a word the element sets on itself while something is true, for styling: epic-choice-row:state(changed). Never written in the file.

State When
changed Its box differs from the recommendation: orange.
stays Claude recommends no change.
  • Order, in a table with reorder (epic epic-workflow P15): its place, then two small grey chevrons, move up and move down, dimmed at either end. A move swaps it with its neighbour, and the focus stays on the button pressed.

  • Purpose: a few words or a sentence, stays when Claude would keep it, the note in small print.
