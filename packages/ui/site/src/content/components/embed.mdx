<Section title="Behaviour">
  Privacy first:  until it's activated, an embed makes no request to the other site, not even a preconnect.  Fomantic
  loaded the frame at once;  here the placeholder is a real `<button>`, and only a click (or Enter / Space) loads the
  `<iframe>`.  YouTube videos play from `youtube-nocookie.com`.

  The video comes from `source` (`youtube` or `vimeo`) plus `video-id` (Fomantic's `data-id`:  `id` is the element's
  own), or from any `http(s)` `url`.  `autoplay` is on by default, since the click already asked for the video;
  `branded-ui` keeps the player's branding, and the `parameters` property adds URL parameters (`{ start: 30 }`).

  Activating fires the cancelable `ui-activate` (`{ url }`);  then the frame loads and focus moves into it.
  `host.activate()` does the same from code;  writing `active` loads without an event.  `host.reset()` goes back to
  the placeholder (and fires `ui-reset`).

```js
const tour = document.querySelector("ui-embed")
tour.parameters = { start: 30 }
tour.addEventListener("ui-activate", (event) => {
  if (!consent.video) {
    event.preventDefault() // keep the placeholder
    askForConsent()
  }
})
tour.reset() // back to the placeholder
```

<Section title="Theming">
  Theme with the public `--ui-embed-*` tokens on the embed or any ancestor;  `::part(embed)` works too.  Style the
  pieces with `::part()`:  `play` (the button), `placeholder` (the image), `icon` and `frame`.  An `aspect-ratio`
  attribute (`4:3`, `21:9`, `square`) replaces `--ui-embed-ratio`, whatever you set.

```css
ui-embed {
  --ui-embed-icon-size: 4em;
  --ui-embed-icon-color: var(--ui-red);
}
ui-embed::part(embed) {
  border-radius: 0.5em;
  overflow: hidden;
}
```

<Section title="Accessibility">
  - The placeholder is a real `<button>` named "Play" plus the `label` ("Play Fomantic UI intro";  translated).  Give
    every embed a `label`:  it also becomes the frame's `title`, which is how screen readers name an `<iframe>`.
  - Once activated, focus moves into the frame, so keyboard users land on the player they asked for.
  - The video's own controls and captions are the other site's.

  | Key           | Action                               |
  | ------------- | ------------------------------------ |
  | Tab           | Reach the play button                |
  | Enter / Space | Load the frame and move focus into it |

  - If the element can't render, its native fallback is the same play button, which swaps itself for the frame:
    the video still plays, and still only after a click.  `ui-activate`, `reset()` and the focus move are lost.
</Section>

<Section title="Framework usage">
  Set `parameters` as a property, and listen for `ui-activate` to gate loading.

```jsx
// React 19
<ui-embed source="youtube" video-id={id} label={title} parameters={{ start: 30 }} onui-activate={track} />
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-embed source="youtube" :video-id="id" :label="title" :parameters="{ start: 30 }" @ui-activate="track" />
```

```jsx
// Solid 2:  no `on:` namespace -- listen through a ref;  `prop:` for the property
<ui-embed source="youtube" video-id={id} label={title} prop:parameters={{ start: 30 }} ref={(el) => el.addEventListener("ui-activate", track)} />
```

</Section>
