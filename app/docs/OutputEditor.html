OutputEditor The open file's compiled javascript, read only.

The JavaScript tab of the editor's Program panel, in Debug: the javascript the open spell file compiled to, to read but not to edit. It changes each time the file compiles. Given a target, it shows the whole project as that target writes it instead: the panel's TypeScript and Python tabs.

In Debug, the editor's page draws it in three of the Program panel's tabs: as OutputRoot, without its toolbar, for the open file's javascript; on its own, with a target, for the project's TypeScript and Python:

SpellEditor.tsx · the Program panel's code tabs · 9 lines
  • OutputRoot is the pane: an OutputToolbar (just its "Javascript Output" header today) above an OutputEditor.
  • OutputEditor is a read-only MonacoEditor, coloured as javascript, showing the open file's compiled code. Monaco loads the first time it's needed.
  • With target (ts/solid or py), it's coloured as that language, and shows what project.codeFor() writes from the last compile. A project that target can't write shows why, as a comment.
  • It doesn't follow the cursor in the code pane.
  • An error drawing it shows in its place, and goes to showError.
