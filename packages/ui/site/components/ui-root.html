Root A root loads the components inside it on demand, sets their theme, size, icons and emoji, and shows them once they're ready. Types

Put one around a page or an app. Each ui-* tag inside loads its component the first time it appears; nothing else is downloaded. Load just the root: import "@spell-app/ui/ui-root".
