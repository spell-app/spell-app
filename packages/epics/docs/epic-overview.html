<epic-overview> The <epic-overview> element: a plan doc's first section, 1. Overview.

<epic-overview> is a plan doc's first section, "1. Overview".

  • It holds the two-sentence summary, the prompt that started the plan, and the Overview's numbered sub-sections.
  • It draws the title bar with its lightbulb, the fold, and the estimate line.

Written for: anyone reading or writing a plan doc's markup, or changing this element.
Status: built in epic-overview/.
Its vocabulary (attributes, slots, parts, children): EpicOverview.en.ts.
The component: EpicOverview.tsx.

Plan docs drawn by Solid web components (<epic-page>, <epic-item> ...) in a new package, epics, loaded by <ui-root> as a component pack, so a doc holds only its data and prose.

  • Its title bar: 1. Overview and a lightbulb, on the section band, sticking under the page header while you read inside it.
  • The estimate line: a clock, Estimate:, then the total, drawn between the prompt and the sub-sections.
  • The sub-sections: numbered 1.1, 1.2 ..., each a nested title on the row band. While the page is reviewed, each has review buttons (Revisit, Make Todo, Do Now: no Approve) and a note box.
  • Folding: a click on the title folds or unfolds it. On a plan doc it starts folded, and the page remembers what you opened. A link into it, or find-in-page, unfolds it.
  • No colour of its own: the summary and the prompt carry the looks (the prompt on ivory, Owen's voice: the colour scheme).
  • spell dev plan-doc new: the template's Overview, with a placeholder summary and one sub-section, o1 "Structure".
  • spell dev plan-doc new --prompt "..." and spell dev plan-doc prompt <name> "...": its <epic-prompt>.
  • estimate: rewritten by every command that changes a phase (spell dev plan-doc add-phase, spell dev plan-doc estimate ...): every phase's estimate added up, and what's left. Absent before the first estimated phase.
  • The summary and the sub-sections' prose: written by hand, by the Claude session planning the epic.
  • spell dev plan-doc status <name> o3 ...: Claude's status cards on a sub-section; a review's Make Todo makes a todo linking it.
  • spell dev plan-doc convert: the old Overview, its slotted summary and prompt turned into <epic-summary> and <epic-prompt> by its second pass.
