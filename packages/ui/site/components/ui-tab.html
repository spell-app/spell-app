Tab A tab is a hidden section of content activated by a menu.

A basic tab.

Two tags: <ui-tab> is the pane (Fomantic's .ui.tab), and <ui-tabs> draws the tab menu from its panes' labels. A pane is hidden until it's the selected one; see the Usage tab. Each <ui-tab> inside a <ui-tabs> is a pane; its label becomes a tab. No script, and no data-tab paths to pair up.

To have a tab visible on page load, give its pane selected (or set the tabs' value); otherwise the first enabled pane shows. First Second Third

Every <ui-tabs> is its own independent tab group, even nested inside another one's pane.

Not ported: Fomantic's context / childrenOnly settings -- a tab set only ever owns its own <ui-tab> children, so groups can't contaminate each other. 1A 1B 1C 2A 2B 2C 3A 3B 3C 4 5 6 1A 1B 1C 2A 2B 2C 3A 3B 3C

A lazy pane stamps its <template> into itself the first time it's shown, so hidden panes cost nothing up front. To fetch content instead, listen for ui-show and fill the pane when event.detail.first is true (see Usage).

Not ported: Fomantic's auto / apiSettings / cache loading -- a fetch is a few lines in a ui-show listener, and the pane's loading shows the spinner meanwhile.
