<epic-link> The <epic-link> element: a link to a saga, an epic, a phase or an item, written by what it points at.

A link to a saga page, an epic page, or a phase or item on one, from any page.

  • It's written by what it points at, never by a path: the same link works from any page, at any depth.
  • With no text inside, it draws the short form: seo J3, just T3 on its own page, P7 · Epic Migrate for a phase.
  • The target's title is its tooltip.
  • It means the same as a short address, SAGA:/<saga>/<epic>#<id>, which a plain link may use too.

For anyone writing links in epic pages, saga pages or guides, or changing this element.
Its vocabulary (every name it uses): EpicLink.en.ts.
Its component: EpicLink.tsx, with its style sheet (.css) and tests beside it.

Its parents: anywhere prose goes, in a paragraph or a list item, on any page that loads the epics pack.

  • Epic pages, saga pages and details pages load it already.
  • A guide loads it with one more line in its <ui-root>: <ui-components source="<up>packages/epics/components/__pack/epics.pack.js">. Without it, use a plain <a href="SAGA:/...">: the docs runtime rewrites it.

Name Values Meaning Required
saga a saga's id Alone: its saga page. With an epic: the saga it names. Not needed; one the epic doesn't name still links, and the link check flags it. no
epic an epic's id Its epic page. no
item an id on that page, any case Lands on it, opening an item: T1, j32, o1. no
phase a number, or a name A phase instead of an item: 7 or P7, the 7th; epic-migrate, the one whose title that is. no

None of saga or epic: the page it's in.

Slot Holds
(default) The link's text; none, the short form.
Name Is
::part(base) The link, an <a>; plain text while it has nowhere to go.
:state(broken) What it points at isn't there: no page, or no such id on it.
  • Inline, in the page's link colour, underlined on hover.
  • Broken: struck through, in the muted ink, its tooltip saying what wasn't found.
  • A link to another epic's page opens in that epic's tab, as every link to an epic page does.
  • Claude and Owen, by hand, in prose.
  • Checked by epic check --links and doc-links.js --check: a saga, page or id that isn't there is a broken link, and so is an epic under a saga it doesn't name.
