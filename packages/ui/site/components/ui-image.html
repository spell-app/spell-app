An image may appear at different sizes.

medium is the image's natural size here, not Fomantic's 300px (I56): elsewhere on this page the medium images are size="large" (450px). Fomantic's default widths for mini ... massive are arbitrary: set the ones your project uses in the --ui-image-width-* tokens (Theming tab).
Size Width
mini 35px
tiny 80px
small 150px
medium natural size (Fomantic: 300px)
large 450px
big 600px
huge 800px
massive 960px
