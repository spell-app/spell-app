AppRoot The running program in the editor's pages, under its toolbar.

The pane where the program you're editing runs, on the editor's page in every mode. It's a toolbar to restart the program, over the box the program draws in, and it tells the editor where that box is.

Written for: anyone changing the spell app's editor, or how it runs programs A picture, not live: the editor's App pane, with Solitaire running in it

The editor's App pane: the purple toolbar is its AppToolbar, and under it, the program draws in an AppContainer.

A picture, taken by yarn site:pictures in spell-app.

The editor page puts it in its right-hand column, with no toolbar, under the program's own header (<AppPane>); in Run, the page keeps that same pane, and only the code column goes:

SpellEditor.tsx · the editor's right-hand column, AppPane · 12 lines
  • Once drawn, it hands its box to the editor with editor.setAppRoot(): that's where the editor runs programs from then on.
  • When it goes, it takes the box back with editor.releaseAppRoot(), but only if it's still the editor's: a page that's leaving may let go after the next page's AppRoot handed its box over. Switching between Edit and Run keeps the same one.
  • <AppToolbar>, above it: an "App" header, then Restart (one of the app's Actions), as an icon. The editor's pages hide it, and draw their own header: the project's group icon and title, then Restart, the Inspector's button and Settings.
  • The program's box scrolls and is padded, unless told not to.
  • A live <spell-viewer> doesn't use it: the runner has its own panes.
