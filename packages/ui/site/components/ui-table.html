A table can scroll horizontally having its head, foot, first or last column keep staying stuck.

You can freely stick any combination like stuck="head first", "foot first last", "head foot first", "first last", etc.

A stuck table possibly needs to be wrapped into an overflowing container like a scrolling container or scrolling segment. If you don't want an extra wrapper, use overflowing on the table; this only works if the table's columns exceed the available width.
