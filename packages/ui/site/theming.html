Using themes

Every colour derives from a few base tokens: re-point --ui-primary or a hue's per-scheme base, and its hover, focus, down and active states, its text, border and background roles follow. Edit a value below to try it on these buttons.

Fomantic's site.variables (@primaryColor, @red ...) are these tokens. A hue's base is a light-dark() pair, --ui-red-on-light / --ui-red-on-dark, so re-colour both to keep dark mode. Primary Button Secondary Button Red Green Blue

Components inherit the global tokens and redefine what's theirs in public --ui-<tag>-* tokens, e.g. checkboxes in your brand colour instead of grey. Each component page lists its tokens on its Theming tab.
