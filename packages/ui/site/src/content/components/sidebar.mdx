<Section title="Behaviour">
  Fomantic's three classes are three elements.  `<ui-pushable>` is the clipping box;  inside it, `<ui-sidebar>`s and
  one `<ui-pusher>`, the page beside them.  A visible sidebar tells its pushable what it needs, and the pushable
  moves, dims or blurs the pusher.  For a whole page, make the pushable the viewport's height:
  `<ui-pushable style="height: 100dvh">`.

  A sidebar is one of two things, following the WAI-ARIA patterns:

  - MODAL (the default):  a drawer.  A `<dialog>` that takes focus and keeps Tab inside;  the pusher is dimmed and
    inert, Escape or a click beside the sidebar closes it, and focus returns to the button that opened it.
    `closedby` says what closes it, as on [`<ui-modal>`](../modal/):  `any`, `closerequest` or `none`.  The page
    doesn't scroll-lock:  only the pusher is blocked.
  - `persistent`:  part of the page.  An `<aside>` landmark (a `<ui-menu>` inside is the `<nav>`), with nothing
    dimmed, inert or trapped, and focus left alone.

  `visible` is the controlled state:  writing it shows or hides the sidebar and fires nothing.  User actions (the
  invoker commands `--show`, `--close` and `--toggle`, Escape, a click beside it) dispatch the cancelable
  `ui-open` / `ui-close` first (`detail.reason` is `escape`, `outside`, `close` or `close-all`), then `ui-show` /
  `ui-hide` after the slide.  A hidden sidebar is `visibility: hidden`:  out of the tab order and the accessibility
  tree, but still laid out.

```js
const menu = document.querySelector("#menu")
menu.addEventListener("ui-close", (event) => {
  if (event.detail.reason === "outside" && pinned) event.preventDefault()
})
menu.visible = true // show from code:  no ui-open
```

<Section title="Theming">
  Theme with the public `--ui-sidebar-*` tokens:  set one on the element, on any ancestor (`:root` for every
  sidebar), or on the box through `::part(sidebar)`.  The width words replace `--ui-sidebar-width`;  `inverted`
  replaces `--ui-sidebar-background`.  `--ui-sidebar-duration`, `--ui-sidebar-dimmer-background` and
  `--ui-pusher-background` are read where they paint (the sidebar, the pusher and its dimmer):  set them on the
  pushable or any ancestor to reach them all, or on the sidebar or the pusher alone.  `blurring` reads the shared
  [dimmer](../dimmer/#theming) tokens.  Style the boxes with `::part(pushable)` and `::part(pusher)`.

```css
ui-sidebar {
  --ui-sidebar-width: 300px;
  --ui-sidebar-background: oklch(0.3 0.05 260);
}
ui-pusher::part(pusher) {
  background: var(--ui-surface);
}
```

<Section title="Accessibility">
  - A modal sidebar is a `<dialog aria-modal="true">` (opened with `show()`, so it stays inside its pushable):  focus
    moves in, Tab stays in, the pusher is inert, and focus returns to the opener when it closes.
  - A `persistent` sidebar is an `<aside>` landmark:  nothing moves focus or blocks the page.
  - Name it with `aria-label`;  otherwise it is "Sidebar" (translated).  Name the menu inside too.
  - Open it from a real button (`commandfor`), so keyboard and screen reader users can reach it.

  | Key               | Action                                                        |
  | ----------------- | ------------------------------------------------------------- |
  | Tab / Shift + Tab | Move between the controls in a modal sidebar (never out)       |
  | Escape            | Close a modal sidebar (`closedby` `any` or `closerequest`)     |

  - If the element can't render, its native fallback is an `<aside>` that follows `visible` and slides over the
    page like an `overlay` sidebar:  no dimming, focus trap, Escape or events.
</Section>

<Section title="Framework usage">
  Bind `visible` to your state and listen for `ui-close` to follow the user.

```jsx
// React 19
<ui-sidebar visible={open} aria-label="Site" onui-close={() => setOpen(false)}>...</ui-sidebar>
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-sidebar :visible="open" aria-label="Site" @ui-close="open = false">...</ui-sidebar>
```

```jsx
// Solid 2:  no `on:` namespace -- listen through a ref
<ui-sidebar prop:visible={open()} aria-label="Site" ref={(el) => el.addEventListener("ui-close", () => setOpen(false))}>
  ...
</ui-sidebar>
```

</Section>
