ProjectDropdown Every project, as a dropdown or a menu of links.

How the editor moves between projects. ProjectDropdown is the dropdown at the left of the editor's top bar, naming the open project after its group's icon; ProjectMenu is the same list as a menu of links, on the page that chooses a project.

  • Both list the projects of one place, a project root: the editor's own, unless projectRoot names another (your projects, the examples, the guides).
  • Choosing one opens it in the editor, or in the runner with useRunner.
  • Both load the root if it hasn't loaded yet. The dropdown spins until it has, and a project is open; the menu says "Loading...", or "Couldn't load" if it fails.
  • The dropdown always shows the open project: choosing one opens it, and only then does the dropdown show it. It's built as FileDropdown is.
  • No label before it: its trigger is the group's icon and the open project's name. Each group has one icon, the same everywhere: a folder for projects, a lightbulb for examples, an open book for guides, a puzzle piece for libraries, a flask for tests.
  • In Run, choosing a project opens it in Run (useRunner).
  • The menu passes every other prop to its <ui-menu>, e.g. vertical.
