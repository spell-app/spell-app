<epic-summary> The <epic-summary> element: the Overview's two-sentence summary, drawn as a lede.

<epic-summary> is what the epic is, in two sentences, at the top of the Overview. It draws its text as a LEDE: the opening paragraph, a size up, in the headings' ink.

Written for: anyone reading or writing an epic page's markup, or changing this element.
Status: built, in the epic-summary folder of the epics package.
Its vocabulary (attributes, slots, parts, children): EpicSummary.en.ts.
The component: EpicSummary.tsx.

Plan docs drawn by Solid web components (<epic-page>, <epic-item> ...) in a new package, packages/epics, loaded by <ui-root> as a component pack, so a doc holds only its data and prose. The plan-doc tool moves into the package as TypeScript, and all 26 docs switch over at once at the end: a layout change becomes an element change, never a rewrite of every doc.
