Content

A set of fields can appear grouped together: <ui-fields>.

Field groups automatically receive responsive styling, swapping to one field per row below 768px of the FORM's width, or of the screen with stack-with="page" (as on this site). Add unstackable to keep a row.

A textarea can be used to allow for extended user input: <ui-textarea>.

To specify an approximate text area size use the rows attribute.

A form can contain a checkbox.

UI checkboxes are special, styled versions of standard HTML checkboxes. They need no script to start.
