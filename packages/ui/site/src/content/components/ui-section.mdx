<Section title="Behaviour">
  ### Section, segment, accordion or header?

  Reach for a section when content needs a TITLE that means something to the page outline, and maybe folding or a
  title that stays in view.  Its neighbours:

  | You want                                                     | Use                                    |
  | ------------------------------------------------------------ | -------------------------------------- |
  | a box or group of content, no title                          | [segment](../ui-segment/)              |
  | a heading on its own, styled                                 | [header](../ui-parts/) (`<ui-header>`) |
  | several panels where opening one may close the others        | [accordion](../ui-accordion/)          |
  | a titled block that can fold, stick, or both, in the outline | `<ui-section>`                         |
  | content that sticks, without a title of its own              | [sticky](../ui-sticky/)                |

  An accordion's titles are buttons, not headings, and its panels are one group;  each section folds on its own and
  its title IS a heading.  A section borrows Fomantic's looks for its box:  `dividing` and `block` from the header,
  `bordered`, `raised`, `attached` and `padded` from the segment, `styled` from the accordion.

  ### Heading levels

  The title renders as `<h1>` ... `<h6>`.  Without `level`, a section takes its enclosing section's level + 1, and a
  top-level one is an `h2` (under the page's `h1`), so nesting sections builds a correct outline by itself.  Set
  `level` where the section sits under a heading that isn't a section (as the examples on this page do), or to
  restart the count.  Levels stop at `h6`.

  ### Folding

  `collapsible` makes the title fold and unfold the content.  `collapsed` is CONTROLLED, as the accordion's `open`
  is:  writing it folds or unfolds and fires nothing.  When the USER activates the title, the cancelable `ui-open` /
  `ui-close` go first, with `{ open, section, originalEvent }`;  `preventDefault()` keeps things as they were.  The
  section folds with a height transition where the browser can animate to `auto` (`interpolate-size`);  with reduced
  motion it snaps.

```js
const section = document.querySelector("ui-section[collapsible]")
section.addEventListener("ui-close", (event) => {
  if (hasUnsavedChanges) event.preventDefault() // stays open
})
section.collapsed = false // unfold from code:  no event
```

  A folded section's content is `hidden="until-found"`:  it stays in the page, so find-in-page (Ctrl / Cmd + F)
  finds text inside it and unfolds the section to show the match.  That unfolding fires `ui-open` with
  `cancelable: false`:  the browser has already revealed the match, so it can't be vetoed.

  ### Sticky titles

  With `sticky`, the title bar sticks to the top of the scroll container while any of its section is on screen, and
  the end of the section pushes it out.  A sticky section INSIDE another sticks just below its parent's title, so
  nested titles stack like breadcrumbs.  `offset` (pixels) moves a TOP-LEVEL section's stuck title down, e.g. below
  a fixed page header;  nested sections work theirs out.  The subhead scrolls away:  only the title bar sticks.
  `:state(stuck)` is set while it is stuck.

  Stuck titles cover what scrolls under them, so a stuck title reserves its room on the scroll container as
  `scroll-padding-top`, as [`<ui-sticky>`](../ui-sticky/) does:  Page Down, Space, focus and `scrollIntoView()`
  keep content out from under the stack instead of hiding the next line behind it.

```css
ui-section:state(stuck)::part(title) {
  box-shadow: 0 2px 4px oklch(0 0 0 / 0.15);
}
```

  ### Slots

  The default slot is the content:  anything, nested sections included.  `header`, `subhead`, `icon` and `badge` each
  have an attribute for plain text and a slot for rich markup;  the slot wins.  `actions` has no attribute:  its
  controls sit at the right of the title bar, OUTSIDE the fold button, so clicking one never folds the section, and
  they stay visible while it is folded.

<Section title="Theming">
  Theme with the public `--ui-section-*` tokens:  set one on the element, on any ancestor (`:root` for every section),
  or on the box through `::part(section)`.  `basic` replaces the box, rule and tint whatever you set.  Style the
  pieces with `::part()`:  `title` (the bar that sticks), `heading`, `toggle` and `fold-icon` (with `collapsible`),
  `icon`, `header`, `badge`, `actions`, `subhead` and `content`.

```css
ui-section {
  --ui-section-scrolling-height: 20em;
}
ui-section::part(heading) {
  letter-spacing: 0.02em;
}
```

<Section title="Accessibility">
  - The title is a real heading, so sections appear in the page outline and screen readers can jump between them.
  - With `collapsible`, the heading CONTAINS the fold button (`<hN><button aria-expanded>`), as the APG accordion
    pattern does:  the heading stays in the outline, and the button says whether the content is shown.  The fold
    icon is decoration;  the button's tooltip says "Fold" or "Unfold" (translatable).
  - The actions are outside the button, so each one is its own tab stop with its own name.
  - Find-in-page reaches folded content and unfolds it.
  - `loading` sets `aria-busy` and announces "Loading…";  `disabled` makes the section inert.
  - Color is never the only signal:  say in the title what a colored section means.

  | Key               | Action                                                    |
  | ----------------- | --------------------------------------------------------- |
  | Tab / Shift + Tab | Move to the fold button, then the actions, then the content |
  | Enter / Space     | Fold or unfold the focused section                        |
</Section>

<Section title="Framework usage">
  Bind `collapsed` and listen for `ui-open` / `ui-close` to follow the user.

```jsx
// React 19
<ui-section header="Details" collapsible collapsed={folded} onui-open={() => setFolded(false)} onui-close={() => setFolded(true)}>
  ...
</ui-section>
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-section header="Details" collapsible :collapsed="folded" @ui-open="folded = false" @ui-close="folded = true">...</ui-section>
```

```jsx
// Solid 2:  no `on:` namespace -- listen through a ref
<ui-section header="Details" collapsible collapsed={folded()} ref={(el) => el.addEventListener("ui-close", () => setFolded(true))}>
  ...
</ui-section>
```

</Section>
