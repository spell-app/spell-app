<Section title="Behaviour">
  Write markdown in a `<script type="text/markdown">` child to keep it exact, or point `source` at a file of this
  site:  its relative links and images resolve beside it.

  Rendering (marked) and sanitizing (DOMPurify) load lazily, with the first markdown shown.  Raw HTML is sanitized
  unless `trusted`.  Headings get GitHub's ids, so `#anchor` links work, and `headings` lists them (with `ui-render`)
  for a table of contents.
</Section>
