<epic-cards> The <epic-cards> element: a saga page's Epics, a card per epic serving the saga, grouped by state.

<epic-cards> is a saga page's Epics: a card for each epic whose page names the saga, in the Epics page's groups. It asks the page server for them, so it is never out of date.

Written for: anyone reading or writing a saga page's markup, or changing this element.
Status: built (epic epic-workflow P15), in the epic-cards folder of the epics package.
Its vocabulary (attributes, parts, texts): EpicCards.en.ts.
The component: EpicCards.tsx.

Attribute Value What it is
saga (required) a saga id The saga whose epics it shows: drawable-spell.

Pieces of what it draws, which a page's CSS can style from outside with ::part(name).

Part What it is
base The box around the groups.
group One group: its heading (icon, title, how many), then its cards.
card One epic's card: its state's mark, linked title, summary and meta line.
note Instead of cards: no epic names the saga yet, the page opened from disk, or no answer.
  • The Epics page's groups, in its order: Active, Planning, Urgent, Done. An empty group isn't drawn. Favorites isn't one here: it's Owen's own list, on the Epics page.
  • Each epic's state and group by the same rule the Epics page uses: in progress blue, errors red, done green, paused and future grey. Its why is the mark's tooltip.
  • Each card: the title links to the epic page, in that epic's own tab; the summary, at most four lines; then the state, phases done of all, and the phase under way.
  • A grid of cards at least 260px wide: one column in the side bar.
  • epic saga page <id>: the saga page template writes it, once.
  • What it draws comes from the page server, GET /api/epics/saga?saga=<id> (SagaEpics): every epic page whose <epic-page saga> names it. It asks again whenever an epic page changes.
