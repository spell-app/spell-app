Spell docs

Every doc, plan and template in the spell monorepo, rendered with @spell/ui.

  • Pages open straight from disk: no server, no build step to read them.
  • The lists below are written by yarn docs:index. Edit only outside its markers.

Writing docs
  • Copy a template from the Templates list into <topic>/<topic>.spell.html.
  • A plan doc: run /plan-doc <name> in Claude Code. Never copy the plan template by hand.
  • The rules: AGENTS.md. How the pages work: spell-docs.md.
  • Then run yarn docs:index so the page shows up here.
