Icon An icon is a glyph used to represent something else. The icon set -- every icon with its name, by category, searchable -- is on the Icons page. Icons are Font Awesome 7 Free SVG files, one per icon, loaded on first use.

Icons sit on the text baseline, one line tall.

An icon can be formatted as a link.

link is only the look (dimmed until hovered, a pointer cursor): wrap the icon in a real <a> or <button> for interaction.

The circular color can appear in the same color as the icon itself.

Not ported: the colored word -- a coloured circular or bordered icon's ring always follows its colour.

An icon can be formatted to appear bordered.
