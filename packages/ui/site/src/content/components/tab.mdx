<Section title="Behaviour">
  Two tags, in Fomantic's own words:  its `.ui.tab` is the PANE, so `<ui-tab>` is a pane, and the tabs you click are
  the items of a menu that `<ui-tabs>` draws from its panes' `label` and `icon`.  One element per tab keeps a label
  with its content, with nothing to pair up.  The tab menu is styled by the menu's own sheet, so its look words are
  the menu's (`tabular`, `pointing`, `secondary`, `text`, `vertical` ...);  the panes are segments.

  `value` is the selected pane:  its `value`, else its index.  Writing it switches panes and fires nothing;  when
  the user picks a tab, the cancelable `ui-change` (`{ value, tab }`) goes first.  With no `value`, the first
  `selected` pane shows, else the first enabled one.  Each time a pane is shown it fires `ui-show`, with
  `first: true` the first time:  the moment to fill a pane yourself.

```js
const tabs = document.querySelector("ui-tabs")
tabs.addEventListener("ui-change", (event) => {
  if (form.dirty && !confirm("Leave unsaved changes?")) event.preventDefault()
})
tabs.value = "photos" // switch from code:  no event
document.querySelector("ui-tab[value=stats]").addEventListener("ui-show", (event) => {
  if (event.detail.first) loadStats(event.target)
})
```

  `history` puts the selection in the URL hash (`#photos`):  picking a tab pushes a history entry, Back and Forward
  switch panes, a link to `#photos` selects that pane, and a page opened on `#photos` starts there.  Where the
  browser has View Transitions, the pane swap runs in one (not under reduced motion).

```html
<ui-tabs tabular attached history aria-label="Profile">
  <ui-tab label="Bio" value="bio">...</ui-tab>
  <ui-tab label="Photos" value="photos" icon="image" lazy><template>...</template></ui-tab>
</ui-tabs>
```

<Section title="Theming">
  The tab menu adopts the [menu](../menu/)'s stylesheet and the panes the [segment](../segment/)'s, so they read
  those families' `--ui-menu-*` and `--ui-segment-*` tokens:  set them on the tab set or any ancestor.  The set's own
  token, `--ui-tabs-pane-margin` (the space between the tab list and the panes), works the same way, or through
  `::part(tabs)`;  attached and vertical sets swap it.  Style the pieces with `::part()`:  on `<ui-tabs>`, `tabs` (the whole set), `menu`
  (the tab list), `tab` (each tab button) and `icon`;  on a `<ui-tab>`, `tab` is the pane's box.

```css
ui-tabs::part(tab) {
  font-weight: 600;
}
ui-tab::part(tab) {
  padding: 2em;
}
```

<Section title="Accessibility">
  The whole APG tabs pattern lives in one shadow root:  a `role="tablist"` (named by the host's `aria-label`) of
  `<button role="tab">`s with `aria-selected` and `aria-controls`;  each `<ui-tab>` host is the `role="tabpanel"`,
  named by its `label`.

  - One Tab stop for the tab list, the selected tab;  the shown pane is the next Tab stop.
  - `activation="manual"` makes the arrow keys move focus only;  Enter or Space then selects.  Use it when showing
    a pane is slow.
  - Disabled tabs stay in the list (announced as unavailable) but the arrow keys skip them.

  | Key                        | Action                                                          |
  | -------------------------- | --------------------------------------------------------------- |
  | Tab                        | Move into the tab list (the selected tab), then to the pane      |
  | Arrow Left / Arrow Right   | Previous / next tab (Arrow Up / Down when `vertical`), wrapping  |
  | Home / End                 | First / last tab                                                 |
  | Enter / Space              | Select the focused tab (`activation="manual"`)                   |

  - If the element can't render, its native fallback still draws the tab list and shows the selected pane, in the
    same class grammar, but a click selects nothing:  the arrow keys, `ui-change`, `history`, `lazy` templates and
    tab icons are lost.
</Section>

<Section title="Framework usage">
  Bind `value` and listen for `ui-change`.

```jsx
// React 19
<ui-tabs tabular attached value={tab} onui-change={(e) => setTab(e.detail.value)}>
  <ui-tab label="Bio" value="bio">...</ui-tab>
</ui-tabs>
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-tabs tabular attached :value="tab" @ui-change="(e) => (tab = e.detail.value)">
  <ui-tab label="Bio" value="bio">...</ui-tab>
</ui-tabs>
```

```jsx
// Solid 2:  no `on:` namespace -- listen through a ref
<ui-tabs tabular attached value={tab()} ref={(el) => el.addEventListener("ui-change", (e) => setTab(e.detail.value))}>
  <ui-tab label="Bio" value="bio">...</ui-tab>
</ui-tabs>
```

</Section>
