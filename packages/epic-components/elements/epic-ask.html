Its parent: a <ui-section id> of a details page, one question each; its answer goes under that id (or its name).

Child How many What it holds
<epic-question> one at most The question, in full.
<epic-choices> one at most Its options, <epic-option>s: each draws a tick box, as an option of an ask.
prose any number Anything else it needs: a table, a picture.
Name Values Meaning Required
name text The key its answer goes under (q1); none: its <ui-section>'s id. Its options' comments are <key>-<letter> (q1-B).
multiple present or absent Pick several (tick boxes); without it, pick one (round ones).
select-all present or absent With multiple: a Select all / Select none button on its line, for the options shown.
filter present or absent An Open | All toggle on its line: Open (the default) hides the options marked done.
more-details present or absent A (?) on each option, "Provide more details": pressed, the option is ticked too, and the answer carries its letter under <key>-more, so Claude explains it in full before asking again.

A slot is a place in the drawing that a child goes to: a child with slot="name" goes to that name's place, every other child to the default one (shown as default).

Slot What goes there
default The question: an <epic-question>, then an <epic-choices>; prose too.

A part is a piece of what the element draws in its shadow root (its own hidden markup), named so a stylesheet can reach it: epic-ask::part(base).

Part What it is
base The question's box.
line Its line: the chip, how to answer, its tools.
chip Its id chip (Q1), in the epic page's state colours: red needs Owen, green picked, blue Claude's.
how Pick one or Pick several.
tools Its buttons: Select all, Open | All.
other The Other box, an <epic-text-box type="other">, after the options.

A state is a word the element sets on itself while something is true, for styling: epic-ask:state(attention). Never written in the file.

State When
attention Nothing picked or written yet: red.
done An option picked: green.
working "Provide more details" asked, or only Other written: blue, Claude's to do.
