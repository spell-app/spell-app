Flag A flag is used to represent a political state. Flags are the Unicode flag emoji, as in Fomantic 2.9's default theme. To return to the sprite approach using the famfamfam icon set, pick the Famfamfam theme above: it draws the 16 x 11 sprite cell for every country it has. Not ported: Fomantic's @flags variable to trim the generated CSS -- there is no per-flag CSS to trim.
