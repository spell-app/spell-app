<Section title="Behaviour">
  Both elements are real form controls:  put them inside a `<form>` and their `name` / `value` is submitted with it
  (a `file` input submits one entry per chosen file).  As with a native input, the `value` ATTRIBUTE is the starting
  value and the `value` PROPERTY the live one;  `form.reset()` goes back to the attribute, and a disabled
  `<fieldset>` disables them.  `readonly` keeps the value in the submission, `disabled` leaves it out.

  Constraint attributes (`required`, `pattern`, `min`, `max`, `step`, `minlength`, `maxlength`) validate natively;
  the `rules` property adds Fomantic's rules on top (`"email"`, `["notEmpty", "minLength[6]"]`).  The field only
  shows as invalid once the user has interacted with it, as `:user-invalid` does.  Enter in a `<ui-input>` submits
  its form;  in a `<ui-textarea>` it types a new line.

  `ui-input` fires on every keystroke and `ui-change` when the user commits (blur, Enter, picking a file).  Setting
  `value` from a `ui-input` handler wins over what was typed, so a handler can reformat or reject input.

```js
const input = document.querySelector("ui-input[name=email]")
input.rules = ["notEmpty", "email"]
input.addEventListener("ui-input", (event) => {
  input.value = event.detail.value.toLowerCase()
})
input.addEventListener("ui-change", (event) => console.log(event.detail.value, input.validity.valid))
```

<Section title="Theming">
  Theme with the public `--ui-input-*` tokens:  set one on the element, on any ancestor (a form, `:root`), or on the
  root box through `::part(input)`.  They inherit into the shadow root, where the sheet reads each through a private
  alias, so nothing inside blocks them;  `<ui-textarea>` reads the same set.  Style the native control with
  `::part(control)`.

```css
ui-input,
ui-textarea {
  --ui-input-radius: 0;
  --ui-input-border-color-focus: var(--ui-primary);
}
ui-input::part(control) {
  font-variant-numeric: tabular-nums;
}
```

<Section title="Accessibility">
  - The shadow root holds a real `<input>` (or `<textarea>`), so typing, selection, autofill and the on-screen
    keyboard come from the browser.  `delegatesFocus` means the host is never a tab stop of its own, and clicking the
    host focuses the control.
  - Name the field with a `<label for>` pointing at the host's `id` (as in a form) or an `aria-label` on the host;
    either becomes the control's accessible name.  A `placeholder` is not a label.
  - A field that fails validation after the user has touched it gets `aria-invalid="true"`;  a `<ui-form>` marks
    failing fields the same way.  `loading` sets `aria-busy`.
  - The `icon` and the `corner` label are decoration;  they are hidden from assistive technology, so don't put
    meaning in them alone.
  - Enter in a `<ui-input>` submits its form (clicking the form's first submit button), as a native field does.
  - Without JavaScript the native fallback keeps the same box with a plain native control:  it still submits,
    validates its native constraints and fires `ui-input` / `ui-change`.  It drops the icon glyph, the `icon`,
    `label` and `action` slots, corner labels, `rules`, the invalid state, reset to the starting value, Enter to
    submit, and naming through `<label for>` (only `aria-label` or `placeholder` name the control).
</Section>

<Section title="Framework usage">
  Set `rules` as a property and listen for `ui-input` / `ui-change`.  Bind `value` as a property to control the field.

```jsx
// React 19
<ui-input name="email" type="email" value={email} rules={["email"]} onui-input={(e) => setEmail(e.detail.value)} />
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-input name="email" type="email" :value="email" :rules="['email']" @ui-input="(e) => (email = e.detail.value)" />
```

```jsx
// Solid 2:  no `on:` namespace, so listen from a ref callback
<ui-input
  name="email"
  type="email"
  prop:value={email()}
  prop:rules={["email"]}
  ref={(el) => el.addEventListener("ui-input", (e) => setEmail(e.detail.value))}
/>
```

</Section>
