Actions The editor's actions, each as a menu item or a button.

Everything a person can tell the editor to do from a toolbar or a menu: Compile, Save, New File, About Spell. Each one is ready to drop into a bar, a "..." menu, or a page as a button, with its own text, icon and click.

  • <Action> is one action: a menu item by default, or a button with button. title is its text, icon its icon, and active lights it up.
  • Actions holds the app's own, each an Action with its text, icon and click filled in, in groups:
    • going places: About Spell, Preview, Settings, Open or Create..., Docs, Help, Log In
    • the project: create, duplicate, rename, delete it; compile, publish, restart it
    • files: create, duplicate, rename, delete, save, reload
    • the console: Clear Console
    • dialogs, for trying them out: alert, confirm, prompt, a number prompt, and choose
  • Props given where it's drawn win over the entry's own: title, icon, onClick ...
  • Some light up as the editor changes: Compile when the file needs compiling, Save and Reload when it has unsaved changes.
  • PROJECT_DROPDOWN_ACTIONS and FILE_DROPDOWN_ACTIONS are the four create / duplicate / rename / delete actions, for the "..." menus in Chrome.
  • In a "..." menu, keep title plain text: the menu draws its items from their text.
