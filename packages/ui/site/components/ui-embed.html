Embed An embed displays content from other websites, like YouTube videos, loaded only when asked for. Types

An embed can be used to display YouTube content. Only a click loads the video, from youtube-nocookie.com.

An embed can display any web content: url frames any http(s) address.

Embeds use an intrinsic aspect ratio to embed content responsively: content keeps its aspect ratio at every browser size.
