Radio A radio button lets a user choose exactly one value of a group.

A radio is an exclusive option: <ui-radio>s with the same name form a group, and choosing one unchooses the rest.

An invisible radio has no box: the label itself is the control, bordered while unchosen and tinted when chosen. Its content can be any markup.

Not ported: styling the label as another component (Fomantic's label class="ui purple button", ui orange message, ui teal segment) -- the label is in the shadow root, so it can't take another component's classes.
