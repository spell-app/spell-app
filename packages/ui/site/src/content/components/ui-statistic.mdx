<Section title="Behaviour">
  A statistic is a value over a label.  Write it with the `value` and `label` shorthands, or slot the generic
  `<ui-value>` and `<ui-label>` [content parts](../ui-parts/):  inside a statistic they take its look (size, colour,
  horizontal, inverted), so there is no separate statistic-label tag.  Slotted parts keep their order;  the `value`
  shorthand always comes before them and the `label` shorthand after, so either shorthand pairs with a slotted part.

  A `<ui-statistics>` group shares its `size`, `color`, `horizontal` and `inverted` with every statistic in it;  a
  statistic's own attribute still wins.  `stackable` answers to the group's own width, not the window's, so a group
  in a narrow sidebar stacks even on a wide screen.  Statistics have no events.

</Section>

<Section title="Theming">
  Theme with the public `--ui-statistic-*` tokens:  set one on the element, on any ancestor (a `<ui-statistics>`
  group, `:root`), or on the box through `::part(statistic)` (the group's box is `::part(group)`).  They inherit into
  the shadow root, where the sheet reads each through a private alias, so nothing inside blocks them.
  `--ui-statistic-value-size` and `--ui-statistic-text-value-size` replace the size ladder's value sizes;
  `horizontal` swaps in its own ladder.  The `value` and `label` parts style the shorthands.

```css
ui-statistics {
  --ui-statistic-horizontal-spacing: 2.5em;
  --ui-statistic-row-spacing: 2em;
}
ui-statistic::part(label) {
  text-transform: none;
}
```

<Section title="Accessibility">
  - A statistic is plain text with no role:  it reads as its value, then its label.  Name a group of statistics
    where it matters, with a heading before it or an `aria-label` on a region around it.
  - Write numbers the way they should be read:  a screen reader says "5,550", not the size or colour around it.
  - An icon inside a value is decorative unless given a `label`;  an image needs its own `alt` (empty when the
    label already says it all).
  - `color` is never the only signal:  say what a red or green value means in the label.
  - Without JavaScript the native fallback renders the same markup, shorthands included, so the value and label
    still show and style.  It drops the spacing between neighbouring statistics;  a failed group keeps its
    statistics visible.
</Section>
