After the animation queue finishes for an element, its final visibility state is determined. An outward transition leaves it hidden; an inward one leaves it visible. Without visible the content starts hidden: out of the page and the accessibility tree.

To force an animation direction, use --show (in) or --close (out), or show() / hide() from script. Showing a shown element does nothing.

If an animation direction is not specified it will automatically be determined based on the element's current visibility: --toggle (or toggle()) runs it out while visible, and in while hidden.
