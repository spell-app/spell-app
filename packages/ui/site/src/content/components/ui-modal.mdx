<Section title="Behaviour">
  The modal is a real `<dialog>` in the element's shadow root, opened with `showModal()`:  the browser moves focus
  into it, keeps Tab inside, makes the rest of the page inert and puts it in the top layer.  Its `::backdrop` is
  the dimmer.  The element adds page scroll lock, closes only the topmost overlay on Escape, and returns focus to
  whatever opened it.

  Open it with no script from a native `<button commandfor="id" command="--show">` or a `<ui-button>` (an invoker
  command);  `--close` closes it and `--toggle` flips it.  From code, set `open`:  writing it is your own decision and fires no
  `ui-open` / `ui-close`.

  `closedby` says what dismisses it, like `<dialog closedby>`:  `any` (the default:  Escape or a click on the
  dimmer), `closerequest` (Escape only) or `none` (only its own buttons).  `closable` adds the close ICON inside
  the box (Fomantic's `closeIcon`), and `closable="false"` also brings back Fomantic's `closable: false` -- no icon,
  and Escape and the dimmer do nothing -- unless `closedby` is set, which wins for dismissal.

  <Example title="Closed only by its buttons" description="`closedby=none`:  Escape and the dimmer do nothing.  The close button is a native invoker, `command=--close`.">
    <button type="button" class="ui button" commandfor="modal-behaviour-none" command="--show">Show</button>
    <ui-modal id="modal-behaviour-none" closedby="none" header="Unsaved changes">
      <ui-content><p>Escape and clicks on the dimmer do nothing here:  only the button closes it.</p></ui-content>
      <ui-actions>
        <button type="button" class="ui button" commandfor="modal-behaviour-none" command="--close">Close</button>
      </ui-actions>
    </ui-modal>
  </Example>

  Buttons anywhere inside act by Fomantic's classes:  `approve` / `ok` / `positive` (or `<ui-button positive>`)
  approve, `deny` / `cancel` / `negative` (or `<ui-button negative>`) deny.  Each first dispatches the cancelable
  `ui-approve` / `ui-deny`, then closes the modal;  `preventDefault()` keeps it open, like Fomantic's `onApprove`
  returning `false`.  The events, in order:

  - `ui-open` (cancelable):  a user asked to open it, through an invoker command.
  - `ui-close` (cancelable):  about to close;  `detail.reason` is `escape`, `outside` (the dimmer), `close` (the
    close icon or `--close`), `approve`, `deny` or `close-all`.
  - `ui-show` / `ui-hide`:  shown or hidden, once the transition has finished.

```js
const modal = document.querySelector("#modal-types-standard")
modal.addEventListener("ui-approve", (event) => {
  if (!form.checkValidity()) event.preventDefault() // stay open
})
modal.addEventListener("ui-close", (event) => console.log(event.detail.reason))
modal.addEventListener("ui-hide", () => console.log("gone"))
modal.open = true // open from code:  no ui-open
```

  For a quick question, `UI.modals.confirm()`, `alert()` and `prompt()` build a small modal for you, open it and
  resolve once it has hidden:  `confirm()` with `true` / `false`, `alert()` with nothing, `prompt()` with the text
  or `null`.  Each takes `{ title, message, okText, cancelText }` (and `value` for `prompt()`);  the buttons
  default to the translated `ok` / `cancel` texts.  Escape answers "cancel";  a click on the dimmer does nothing,
  so a stray click can't answer.

<Section title="Theming">
  Theme with the public `--ui-modal-*` tokens:  set one on the element, on any ancestor (`:root` for every modal),
  or on the box through `::part(modal)`.  They inherit into the shadow root, where the sheet reads each through a
  private alias, so nothing inside blocks them.  `--ui-modal-dimmer-background` colours the backdrop (by default the
  shared `--ui-dimmer-background`, which also themes `<ui-dimmer>`).  A `--ui-modal-width` holds on every screen;
  `fullscreen` replaces it.  The header, content and actions parts read `--ui-modal-header-*`,
  `--ui-modal-content-background` and `--ui-modal-actions-background` from the modal, so set those on the modal or
  above it;  `basic` replaces them.

```css
:root {
  --ui-modal-radius: 0.75em;
}
ui-modal.confirm {
  --ui-modal-width: 480px;
  --ui-modal-dimmer-background: oklch(0 0 0 / 0.6);
}
```

<Section title="Accessibility">
  - A real modal `<dialog>`:  focus moves inside and Tab stays there, the rest of the page is inert, and focus
    returns to the opener when it closes.
  - Named by the host's `aria-label`, else the `header` shorthand, else a slotted `<ui-header>`.
  - The close icon is a real button named "Close" (translated), placed last, so the first focus lands in the content
    (a confirm's Cancel), not on it.  Put `autofocus` on the control that should take focus first.
  - Escape closes it unless `closedby="none"`;  with `closedby="none"`, make sure a button inside closes it.
  - Open it from a real button (`commandfor`), so keyboard and screen reader users can reach it the same way.

  | Key                 | Action                                                    |
  | ------------------- | --------------------------------------------------------- |
  | Tab / Shift + Tab   | Move between the controls inside the modal (never out)    |
  | Enter / Space       | Activate the focused button (approve, deny, close)        |
  | Escape              | Close it (`closedby` `any` or `closerequest`)             |

  - If the element fails to render, its native fallback is the same `<dialog>`, shown with `showModal()` while the
    host has `open`:  it still traps focus, dims the page, closes on Escape, and fires `ui-approve` / `ui-deny`.
    It drops invoker commands (open it by setting `open`), `ui-open` / `ui-close` vetoes, `ui-show`, `closedby`,
    scroll lock and the translated close label (a `×` stands in for the icon).
</Section>

<Section title="Framework usage">
  Bind `open` to your state and listen for `ui-close` (and `ui-approve` / `ui-deny`) to follow the user.

```jsx
// React 19
<ui-modal open={open} header="Delete?" onui-close={() => setOpen(false)} onui-approve={remove}>...</ui-modal>
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-modal :open="open" header="Delete?" @ui-close="open = false" @ui-approve="remove">...</ui-modal>
```

```jsx
// Solid 2:  no `on:` namespace, so add `ui-*` listeners in a ref callback
<ui-modal
  prop:open={open()}
  header="Delete?"
  ref={(el) => {
    el.addEventListener("ui-close", () => setOpen(false))
    el.addEventListener("ui-approve", remove)
  }}
>
  ...
</ui-modal>
```

</Section>
