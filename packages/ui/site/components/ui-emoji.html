Emoji An emoji is a glyph used to represent something else. Types Not ported: Fomantic's <em data-emoji> images from a CDN (Twemoji, JoyPixels) -- an emoji is the reader's own Unicode glyph, so there is no download and no per-emoji CSS (image sets: I1).

You can provide the emoji's name with or without colons.

A name is case-blind, and its words may be joined any way: thumbs_up, thumbs up, thumbs-up, thumbsUp, thumbsup. No build setting needed (Fomantic 2.10's @variationEmojiNoColons).

An emoji can vary in size.

Sizes are ratios of the surrounding text: small 1.5em, large 6em, big 7.5em. medium is the default, the size of the text -- NOT Fomantic's fixed 3em. Small

An emoji can be formatted as a link.

link is only the look, a pointer cursor: wrap the emoji in a <ui-button> or <a> that does the work, and name that. Fomantic's names

A page written for Fomantic's emoji list can keep its names: a <ui-root emoji="fomantic"> around them switches every emoji inside to Fomantic's set (thumbsup, smile, flag_us, one for the keycap), with Fomantic's meanings: dog is the dog's face there, the whole dog in CLDR.

The two sets are never mixed inside a root, so the CLDR names stop working there. A page with no root switches page-wide from JS with EmojiData.use("fomantic").
