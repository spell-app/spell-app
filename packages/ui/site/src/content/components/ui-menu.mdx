<Section title="Behaviour">
  A menu's children are the one generic [`<ui-item>`](../ui-item/):  the menu tells each item how to render, so there is no
  `ui-menu-item`.  An item with `href` is a link;  with `link`, or in a `link`, `pagination` or `interactive` menu, it is
  a button;  otherwise a plain block that can hold text, inputs or a dropdown.  A `<ui-menu>` inside a menu (directly,
  or inside an item) is a sub menu:  `position` places it (`right` for Fomantic's right menu), and its items look like
  the outer menu's.

  A menu comes in two kinds.  By default it is site navigation:  a `<nav>` landmark of links, the `selected` one
  marked as the current page.  `interactive` makes it an application menubar instead, for commands:  one Tab stop,
  arrow keys between the items.

  `ui-select` fires when a link or button item is activated (click, Enter or Space);  `detail.value` is the item's
  `value`, else its text, and `detail.item` is the `<ui-item>`.  Only the top menu fires it, for sub-menu items too.
  The menu never moves `selected` itself:

```js
const menu = document.querySelector("ui-menu[interactive]")
menu.addEventListener("ui-select", (event) => {
  for (const item of menu.querySelectorAll("ui-item")) {
    item.toggleAttribute("selected", item === event.detail.item)
  }
})
```

<Section title="Theming">
  Theme with the public `--ui-menu-*` tokens:  set one on the element, on any ancestor (a header, `:root`), or on the
  menu's box through `::part(menu)`.  The items read them from the menu, so set them there or above, not on an item.
  A variation (`secondary`, `tabular` ...) swaps its own values in over yours.  Style an item's box with
  `ui-item::part(item)`.

```css
ui-menu {
  --ui-menu-radius: 0;
  --ui-menu-item-padding: 0.75em 1.5em;
}
```

<Section title="Accessibility">
  - By default the shadow root holds a `<nav>` landmark.  Name it with `aria-label` on the `<ui-menu>`:  two
    navigation menus on one page need different names.  The `selected` link item is `aria-current="page"`.
  - In a `link` or `pagination` menu the items without `href` are `<button>`s;  a selected button item is
    `aria-current="true"`.
  - `interactive` renders a `role="menubar"` (with `aria-orientation="vertical"` when `vertical`), named the same way.
    Each item's box is a `menuitem` and the item element itself has `role="none"`.  The menubar is one Tab stop:  it
    lands on the selected item, else the first, and the arrow keys move between items, skipping disabled ones.
  - `type=header` items are plain text, not links or menu items.
  - An icon-only item needs a name:  put `aria-label` on the `<ui-item>`.
  - `disabled` removes a link's `href` (and sets `aria-disabled`), disables a button, and marks a menu item
    `aria-disabled`.

  | Key                      | Action (`interactive` menubar)                                       |
  | ------------------------ | -------------------------------------------------------------------- |
  | Tab                      | Enter the menubar on the selected (else first) item;  Tab again leaves |
  | Arrow Right / Arrow Left | Next / previous item, wrapping at the ends (flipped right-to-left)    |
  | Arrow Down / Arrow Up    | Next / previous item in a `vertical` menubar                          |
  | Home / End               | First / last item                                                     |
  | Enter / Space            | Activate the item (`ui-select`)                                       |

  A navigation menu keeps the browser's own keys:  Tab moves through its links and buttons, Enter follows them.

  If the element can't render, its native fallback keeps the same `<nav>` (or sub-menu `<div>`) with the same class
  words, so the menu still looks right and its links work.  It drops `ui-select` and the menubar:  an `interactive`
  menu becomes a plain `<nav>` with no arrow keys or `menuitem` roles.
</Section>

<Section title="Framework usage">
  Define the elements first, then listen for `ui-select` with your framework's custom-event syntax.

```jsx
// React 19
<ui-menu interactive aria-label="Editor" onui-select={(e) => run(e.detail.value)}>...</ui-menu>
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-menu interactive aria-label="Editor" @ui-select="(e) => run(e.detail.value)">...</ui-menu>
```

```jsx
// Solid 2:  no `on:` namespace, so listen from a ref
<ui-menu interactive aria-label="Editor" ref={(el) => el.addEventListener("ui-select", (e) => run(e.detail.value))}>
  ...
</ui-menu>
```

</Section>
