The Brand Elements Every <brand-*> element the Brand tab's pages are built from, how to load them, and a page for each.
Written for: anyone building a page in Spell's brand, or changing one of its elements Status: built every tag in components/ The pages they're for: the Brand tab
  • They're a COMPONENT PACK: brand.pack.js, one script, built by spell dev pack build brand.
  • A page names it in its <ui-root>, which loads it the first time a brand- tag shows up, and draws each tag's skeleton until then.
  • Each element is a Spell UI element: it reads Spell UI's tokens, and the brand roles (--spell-*) of the spell-brand theme where the page has it.
A page with the brand's elements · 4 lines

The Brand tab's own copies load the whole brand bundle instead (brand-ui.js, with the spell-brand theme): the brand package's notes.

Tag What it is
brand-color A square colour chip: a label inside, an AA mark, a selected ring, a details tip; click to copy.
brand-color-set Colour chips in a row or a grid; selectable makes it a radio group to pick one.
brand-color-range A 17-step ladder of shades made from one base colour, the base colour's step ringed.
brand-color-picker Chooses a colour by lightness and colourfulness for a hue, or by typing its hex or OKLCH.
Tag What it is
brand-field One control with its label, a value readout, action buttons, an info tip, help and errors.
brand-composer The box where you describe an app in plain words and cast it: a serif text box, tool chips, a keyboard hint and a round Cast button.
Tag What it is
brand-checklist A build's progress step by step, or a list of things to tick off, each with a round mark; its lines are brand-checks.
brand-phone Live app content framed as a phone: a status bar on top, the app below.
Tag What it is
brand-logo The Spell logo: the hat mark, or the mark with the wordmark (and tagline), outlined, in one colour.
brand-flourish Generated page art (swoops, blobs, curls, sparkles) behind its parent's content.
brand-blob One soft lavender shape tucked into a corner of its parent, never behind body text.

Brand fields in Spell UI's panels, as the Theme Creator's inspector has them: an info tip, a value readout, action buttons, help and an error.
