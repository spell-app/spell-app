Where we're going

Each goal set is a plan for one project or idea: a page per topic, with goals, questions, decisions, and notes agents can build from.

1. Goal sets

2. How it works
  • Talk: /goals spell/motivation in Claude Code (or the speech button on a page) starts a dialog; answers become decisions, goals and work.
  • Jot: the thought bubble beside any section or item saves a note for later; /goals-thought spell/motivation/G1 does it from the command line.
  • Digest: /goals-update works your thoughts into the pages.
  • Read: /goals-open opens a page in your browser, /goals-open-vs beside your code in VS Code. Pages update by themselves while the goals server runs.

Preferences: goals.preferences.json5, in the goals folder.
