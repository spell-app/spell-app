<Section title="Behaviour">
  A loader shows only while it is `active`, so you can leave it in place and toggle the attribute;  `disabled` hides
  it again.  Without `inline` it is centred over the nearest ancestor with `position: relative` (or any other
  positioning), across component boundaries, so it covers that box whatever the markup in between.  With `inline` it
  sits in the line of text instead.

  To show that a whole block of content is loading, a [segment](../ui-segment/) with `loading` already draws its own
  spinner and announces it.  Loaders have no events.

```js
const loader = document.querySelector("ui-loader")
loader.toggleAttribute("active", true)
await saveChanges()
loader.toggleAttribute("active", false)
```

<Section title="Theming">
  Theme with the public `--ui-loader-*` tokens:  set one on the element, on any ancestor (a region, `:root`), or on
  the inner box through `::part(loader)`.  They inherit into the shadow root, where the sheet reads each through a
  private alias, so nothing inside blocks them.  `--ui-loader-slow` and `--ui-loader-fast` are ratios of
  `--ui-loader-speed`, so one change paces every style.

```css
/* every loader on the page */
:root {
  --ui-loader-speed: 0.8s;
}
/* one kind, on its box */
ui-loader.thick::part(loader) {
  --ui-loader-line-width: 0.3em;
}
```

<Section title="Accessibility">
  - The loader is a polite live region (`role="status"`):  screen readers announce it without interrupting.
  - Its name is its text, or "Loading…" (translatable) when it has none.  The spinner itself is decorative.
  - Mark the region that is loading with `aria-busy="true"` while the loader is active, so its half-loaded content
    isn't read out.
  - With reduced motion turned on, the spinner shows a still arc;  the status and its text still carry the message.
  - Without JavaScript the native fallback renders the same loader with the status role on it, named "Loading…" in
    English when empty;  that name doesn't follow later changes to the text.
</Section>
