A modal can contain a row of actions: <ui-actions>.

Buttons anywhere inside act by Fomantic's classes: approve / ok / positive (or <ui-button positive>) approve, deny / cancel / negative (or <ui-button negative>) deny. Each fires the cancelable ui-approve / ui-deny, then closes the modal. To keep a modal open after an action, call preventDefault() on its ui-approve / ui-deny event (Fomantic's callback returning false). Show
