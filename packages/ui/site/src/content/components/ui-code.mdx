<Section title="Types">

<Section title="Behaviour">
  Write code with `<` or `&` in a `<script type="text/plain">` child:  its text is taken exactly.  Otherwise the
  element's own text is used, dedented.  Or point `source` at a file of this site.

  highlight.js loads lazily, with the first code shown.  `UI.code.register(name, language)` adds a language:  a
  highlight.js grammar, a highlighter of your own returning `{ start, end, kind }` spans, or a `load()` that fetches
  either on first use.  An unknown language shows plain text and fires a `ui-error` (`kind: "render"`).

  Colours are `--ui-code-<group>` tokens (`keyword`, `string`, `number`, `comment`, `title`, `type`, `attr`, `meta`
  ...), light and dark.
</Section>
