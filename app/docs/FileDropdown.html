FileDropdown The open project's files, as a dropdown showing the open one.

How the editor switches between a project's files: a dropdown showing the open file's icon and name. Choosing another opens it in the editor.

The toolbar above the editor's input pane starts with it, before the file actions. As InputEditor's toolbar draws it:

InputEditor.tsx · the input toolbar · 14 lines
  • It lists the files of the editor's open project, and shows the open one. Choosing one opens it in the editor, or in the runner with useRunner.
  • It spins, with no items, until the project has loaded and a file is open.
  • It always shows the open file: choosing one opens it, and only then does the dropdown show it.
  • showActions adds the file actions after a divider: choosing one does it, as the MoreMenu does.
  • It sits in a menu, wrapped in a menu item. No label before it: the file icon and the open file's name are its trigger.
