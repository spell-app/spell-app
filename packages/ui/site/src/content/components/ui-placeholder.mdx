<Section title="Behaviour">
  Build a skeleton from four shapes inside a `<ui-placeholder>`:  `<ui-placeholder-header>` (two taller bars, with an
  optional square `image`), `<ui-placeholder-paragraph>`, `<ui-placeholder-line>` and `<ui-placeholder-image>`.  The
  shapes must sit inside a `<ui-placeholder>`:  that is where their look comes from.  A shimmer sweeps across every
  shape on the page in step;  it stops when the reader prefers reduced motion.

  A placeholder has no events and no "loaded" state:  replace it with the real content when that arrives.

```html
<section aria-busy="true">
  <ui-placeholder>
    <ui-placeholder-paragraph>
      <ui-placeholder-line></ui-placeholder-line>
      <ui-placeholder-line></ui-placeholder-line>
    </ui-placeholder-paragraph>
  </ui-placeholder>
</section>
<!-- when the data is in:  swap the placeholder for the content, then remove aria-busy -->
```

<Section title="Theming">
  Theme with the public `--ui-placeholder-*` tokens:  set one on the element, on any ancestor (a region, `:root`), or
  on the inner box through `::part(placeholder)`;  every shape inside follows.  They inherit into the shadow roots,
  where the sheet reads each through a private alias, so nothing inside blocks them.  A single shape takes them too,
  on its own element or `::part()`.  The colours are tints of the ink colour, so they suit any surface in either
  scheme.

```css
/* every placeholder on the page */
:root {
  --ui-placeholder-duration: 3s;
}
/* one region */
.sidebar {
  --ui-placeholder-max-width: 40em;
  --ui-placeholder-radius: 0;
}
```

<Section title="Accessibility">
  - A placeholder is decorative:  it is hidden from screen readers and holds no text.
  - Announce the loading once, on the region that is loading:  `aria-busy="true"` on it, a
    [loader](../ui-loader/), or a [segment](../ui-segment/) with `loading`.
  - The shimmer stops for readers who prefer reduced motion;  the shapes stay as a flat tint.
  - Without JavaScript the native fallback renders the same shapes with the same class words, still hidden from
    screen readers, so nothing is lost.
</Section>
