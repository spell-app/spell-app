Chooser A dialog to choose one value from a list, or several.

The dialog the editor shows when it needs a person to pick from a short list. It's a list of radio buttons (or checkboxes, to pick several), with Cancel and OK, and it hands back what was picked.

  • Call editor.choose() to ask: it needs a message and its options. It opens the chooser with openChooser(), which adds it to the page and takes it away once it's closed.
  • options can be plain values, { value, text } objects, or a map of value to text. The answer is the caller's own value: a number option answers a number.
  • The answer, once the dialog has gone: OK gives the value picked (with multiple, a list of them); Cancel or Escape gives undefined.
  • defaultValue picks some to start with. Enter anywhere in it is OK; a click outside it does nothing.
  • It looks like the editor's other dialogs: small, Cancel first. It's a plain list, fine for a handful of options; a long one would want a searchable dropdown.
