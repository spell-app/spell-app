Brand

How spell looks and sounds everywhere: a visual language made with Claude Design, carried through the app, the website and the docs.

Status: draft · first pass, not yet talked through Updated: 2026-10-01 Notes for agents: brand.md

1. Summary
  • No brand yet: no logo, palette, type, or voice guide. The app and docs wear @spell-app/ui's default Fomantic look.
  • The plan: make a visual language with Claude Design (logo, color, type, components, illustration, voice), then ship it as an @spell-app/ui theme, so the app, website, docs and spells share one look.
  • Ready for it: @spell-app/ui is themed through --ui-* tokens, with light and dark built in.

2. Today
  • Theming: packages/ui/docs/theming.md; tokens in packages/ui/src/styles/tokens.css and colors.css (OKLCH, light-dark()).
  • Docs pages: system fonts and UI tokens (packages/docs/tools/_assets/spell-doc.css); this master plan adds a stacked-card look (packages/docs/tools/_assets/goals.css).
  • Names we hold: the GitHub org spell-app, the npm scope @spell-app (nothing published). Old notes imagine spell.app.

4. Ideas
  1. I1 Cards and stacks as the motif a nod to HyperCard: index cards, stackeddetails

    This master plan already tries it: the hero box and topic cards have cards stacked behind them.

  2. I2 Magic, lightly a spell is words that make things happen; no wizard hats on everything
  3. I3 Spell code in a reading font it's English: maybe show it in a proportional face, not monospacedetails

    A bold, distinctive choice. Indentation still matters, so tabs need care.
  4. I4 Two layers spell's own brand vs. the neutral default for things people make

5. Questions
  1. Q1 What should it feel like? warm and handmade? crisp? playful? a little nostalgic?details

    Suggestion: warm and crafted, like a well-made notebook: inviting to a non-programmer, credible to a programmer. Nostalgia in small doses (the card stacks).

  2. Q2 The magic metaphor: lean in or play down? spells, incantations, wands... or just the name
  3. Q3 Name and domain do we own spell.app? is "spell" findable?details

    "Spell" is a common word, and other products have used it. Search will be hard unless the domain and tagline do the work.

  4. Q4 Spell code in a proportional font? see I3
  5. Q5 Keep Fomantic's look underneath? restyle through tokens, or a deeper redesign
  6. Q6 References you love sites, apps or brands to learn from

6. Risks
  1. R1 Bikeshedding brand work expands to fill any time given: time-box it
  2. R2 A name people can't find "spell" collides with the word, and with other products
  3. R3 Brand on the website, not in the app the theme must live in @spell-app/ui, not in a stylesheet
