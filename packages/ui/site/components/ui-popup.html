An element can specify a simple tooltip that can appear without JavaScript via the data-tooltip attribute. If the tooltip should be shown inverted, also add the data-inverted attribute.

Tooltips use an element's ::before and ::after pseudo-elements, and screen readers don't reliably announce them: use them for hints only, and a <ui-popup> for anything that matters. A tooltip can vary in size via the data-variation attribute.

The data-variation attribute takes several words, just like a class would: sizes, basic, fixed, multiline, visible and colours. Mini Tiny Small Medium Large Huge Mini Tiny Small Medium Large Huge Basic Tiny Basic Basic Tiny Basic

A tooltip can show multiple lines via line breaks in the attribute and adding multiline to the data-variation attribute.

A popup can be extra wide to allow for longer content: wide, wide="very".

A popup's width is capped by its maximum width, so short content stays narrow even when it is wide. Add fixed to make it always that wide; the CSS-only tooltip takes fixed, wide fixed and very wide fixed in its data-variation.
