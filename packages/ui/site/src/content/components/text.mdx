<Section title="Behaviour">
  `<ui-text>` is an inline span that flows with the text around it.  Its size is relative to that text, and it
  ignores the colour and size of a component it sits in:  red text inside a large blue button is red, at the
  button's text size, never scaled twice.  Text without a `color` inherits its colour.  Text has no events.

  <VocabularyTable family="text" />
</Section>

<Section title="Theming">
  Theme with the public `--ui-text-*` tokens:  set one on the element, on any ancestor (a region, `:root`), or on the
  inner box through `::part(text)`.  They inherit into the shadow root, where the sheet reads each through a private
  alias, so nothing inside blocks them.  The hues themselves are global colour tokens (`--ui-red` and friends), so
  change those to recolour every component at once.

```css
/* every text on the page */
:root {
  --ui-text-disabled-opacity: 0.6;
}
/* one region */
.headline {
  --ui-text-line-height: 1.2;
}
```

</Section>

<Section title="Accessibility">
  - Colour is never the only signal:  `state="error"` is only a colour, so the words must say it is an error too.
    Use `role="alert"` or a live region when it has to be announced.
  - Coloured text uses each hue's text shade, tuned to reach 4.5:1 contrast on the page background in both light and
    dark schemes.  `inverted` switches to the shade meant for dark surfaces.
  - `disabled` only fades the text;  it does not hide it from screen readers.
  - Without JavaScript the native fallback renders the same `<span>` with the same class words, so nothing is lost.
</Section>
