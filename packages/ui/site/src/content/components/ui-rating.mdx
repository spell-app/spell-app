<Section title="Behaviour">
  A rating is a form control.  With a `name` it submits its `value` with the form while it is above 0;  `required`
  makes a rating necessary, and a form reset puts back the starting `value` (the attribute).  The `value` property is
  the live rating.  `ui-change` fires when the user rates, with `0` when they clear it;  setting `value` back inside
  the handler vetoes the change.

```js
const rating = document.querySelector("ui-rating")
rating.addEventListener("ui-change", (event) => console.log(event.detail.value))
```

  `clearable` lets the user take a rating back by choosing the current one again, or with Backspace / Delete;  a
  one-icon rating is always clearable.  A fractional `value` (`3.5`) only draws a partial icon.

</Section>

<Section title="Theming">
  Theme with the public `--ui-rating-*` tokens:  set one on the element, on any ancestor (`:root` included), or on
  the group's box through `::part(rating)`.  They inherit into the shadow root, where the sheet reads each through a
  private alias, so nothing inside blocks them.  Style one icon with `::part(icon)`.

```css
ui-rating {
  --ui-rating-icon-width: 1.5em;
  --ui-rating-inactive-color: var(--ui-border-color);
}
```

<Section title="Accessibility">
  The rating is a group of real radios:  one per icon, each named "3 of 5" (translatable).

  - The group is a `radiogroup` named by the host's `aria-label` or a `<label for>`.  A fractional rating adds a
    description, "Rated 3.5 of 5".
  - `readonly` stays focusable and announced but can't change;  `disabled` leaves the tab order.
  - Colour is never the only signal:  filled and empty icons differ in shape and the radios carry the count.
  - If the element can't render, its native fallback is the same group of real radios, numbered instead of icons,
    so the rating still works and submits;  colours, sizes, the hover preview, partial icons, `clearable` and
    Home / End are dropped.

  | Key                          | Action                                               |
  | ---------------------------- | ---------------------------------------------------- |
  | Tab                          | Move into the rating (one stop), then out            |
  | Arrow Right / Arrow Down     | Choose one more (wraps to the first)                 |
  | Arrow Left / Arrow Up        | Choose one less (wraps to the last)                  |
  | Home / End                   | Choose the lowest / highest rating                   |
  | Space                        | Choose the focused icon                              |
  | Backspace / Delete           | Clear a `clearable` rating                           |
</Section>

<Section title="Framework usage">
  `value` is a plain attribute;  listen for `ui-change`.

```jsx
// React 19
<ui-rating name="food" max-rating={5} value={stars} onui-change={(e) => setStars(e.detail.value)} />
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-rating name="food" max-rating="5" :value="stars" @ui-change="(e) => (stars = e.detail.value)" />
```

```jsx
// Solid 2:  no `on:` namespace -- listen through a ref
<ui-rating name="food" max-rating="5" value={stars()} ref={(el) => el.addEventListener("ui-change", (e) => setStars(e.detail.value))} />
```

</Section>
