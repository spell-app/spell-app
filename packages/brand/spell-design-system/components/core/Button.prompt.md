Pill-shaped button for actions; use `primary` for the single main action per view, `ink` for marketing CTAs on light grounds.

```jsx
<Button variant="primary" leadingIcon={<i className="fa-solid fa-wand-magic-sparkles" />}>Build</Button>
<Button variant="secondary">Cancel</Button>
<Button variant="soft" size="sm" trailingIcon={<i className="fa-solid fa-arrow-right" />}>Open app</Button>
```
Variants: primary · ink · secondary · soft · ghost · danger. Sizes: sm (30) · md (36) · lg (44). Press scales to 0.97.
