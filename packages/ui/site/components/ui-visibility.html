Visibility Visibility provides a set of callbacks for when content appears in the viewport. Usage

Visibility reports an element's position on screen: wrap the content in <ui-visibility> and listen for its events, each with the calculations as detail. Scroll the page and watch the table: it updates at every check.

Checks happen when something crosses (the element entering or leaving, an edge crossing the screen's top or bottom), not on every scrolled pixel: visibility runs on IntersectionObserver, with no scroll listener. The table beside the demo is filled by this page's script from the events.

By default each event fires only the first time its conditions are met. once="false" fires it each time its condition becomes true, and continuous at every check while it holds. Each segment below counts its ui-top-visible events: scroll them out of view and back.

Events occur at the first check where their conditions turn true. Each is Fomantic's callback as a ui-* event. The log below shows the demo's events as you scroll past it.

Event Fomantic's callback Occurs
ui-visible onOnScreen Any part of the element is on screen
ui-hidden onOffScreen No part of the element is on screen
ui-top-visible onTopVisible The element's top edge has passed the bottom of the screen
ui-top-passed onTopPassed The element's top edge has passed the top of the screen
ui-bottom-visible onBottomVisible The element's bottom edge has passed the bottom of the screen
ui-passing onPassing The element spans the top of the screen
ui-bottom-passed onBottomPassed The element's bottom edge has passed the top of the screen
Scroll the page: events appear here, newest first. Not yet: Grouped Events -- Fomantic's onPassed: { 40: fn, "80%": fn }, callbacks after a distance into the element. There is no event or UI.observeVisibility() option for them.

Reverse events occur under the same conditions, but as the user scrolls back up the page: UI.observeVisibility(element, options) takes Fomantic's ...Reverse callbacks (the element has no events for them). The log shows this demo's reverse callbacks.
