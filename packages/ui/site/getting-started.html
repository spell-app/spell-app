General Usage

Fomantic's base concept is descriptive class names on HTML nodes; Spell UI's is descriptive ATTRIBUTES on ui-* tags. The tag's ui- prefix does the namespacing Fomantic's ui class did.

Button Button

Fomantic needs some class names in a strict order (ui left labeled right floated button, never ui left right button floated labeled). Attributes have no such rule: each names its own side, so any order renders the same.

Until then: yarn in the monorepo, and yarn build in packages/ui writes dist/. Not ported: Fomantic's gulp build, semantic.json, CDN links and separate CSS / LESS / SASS distributions -- one package holds the elements, their CSS and the token sheets, and themes are CSS files you add, not a build.
