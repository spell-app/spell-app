<Section title="Behaviour">
  A grid is 16 columns wide.  Put `<ui-column>`s straight in a `<ui-grid>` and they wrap onto new lines as they fill
  one;  wrap them in a `<ui-row>` to force a line break or give one line its own settings.  A column's width comes
  from, in order:  its own `width`, its row's `columns`, its grid's `columns`, filling the line when it is the only
  child, else one of 16.

  Rows and columns take no box of their own inside a grid, so style them through `::part(row)` and `::part(column)`.
  A top-level `<ui-grid>` measures its own width for the responsive variations, which means it can't take its size
  from its content:  inside a flex or inline layout, give it a width.  Grids have no events.

</Section>

<Section title="Theming">
  Theme with the public `--ui-grid-*` tokens:  set one on the grid element, on any ancestor (a region, `:root`), or
  on the grid's box through `::part(grid)` (or on `.ui.grid` in your app stylesheet);  its rows and columns follow.
  They inherit into the shadow roots, where the sheet reads each through a private alias, so nothing inside blocks
  them.  `relaxed` and `compact` swap in their own gutter tokens (`--ui-grid-relaxed-gutter` ...), whatever the
  base gutter.

```css
/* every grid on the page */
:root {
  --ui-grid-divider-color: var(--ui-border-color-strong);
}
/* one grid */
ui-grid.roomy {
  --ui-grid-gutter: 3em;
}
```

<Section title="Accessibility">
  - A grid is layout only:  plain boxes with no role.  Put headings, lists and landmarks inside the columns.
  - Screen readers and the Tab key follow the source order, so `reversed` and `floated` change only what the eye
    sees.  Keep the source in a sensible reading order.
  - `only` hides rows and columns with `display: none`, from assistive tech too.  Don't put anything there that the
    other devices need.
  - `color` fills a row or column with a hue and switches its text to a contrasting colour;  check any colours you
    add inside.
  - Without JavaScript the native fallback renders the same grid, row and column boxes with the same class words
    (widths included), so the layout is unchanged.
</Section>
