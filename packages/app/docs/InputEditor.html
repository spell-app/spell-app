InputEditor The spell source editor on the open file, with its toolbar.

Where you write spell in the editor: the open file, coloured as spell, top left, with a toolbar to pick another file, compile, save, reload or make a new one. It's a Monaco editor on the file, so it has hovers, references and "go to definition" too.

Written for: anyone changing the spell app's editor, or reading its code A picture, not live: it needs the whole editor, and a project open in it

  • InputRoot is the pane: an InputToolbar above an InputEditor.
  • The toolbar: the file dropdown on the left; Compile, Save, Reload, New File and the file's "..." menu on the right.
  • InputEditor edits the editor's open file. Monaco loads the first time it's needed, so it says "Loading editor…" till then, and a fresh editor is made for each file.
  • Once it's made, the editor gets it: for its save, reload and compile keys, and to follow the cursor and scrolling. It selects where the file asked to open, such as a definition jumped to.
  • On an error, showError is told, and a plain editor with no spell colouring takes over, in case the colouring is what failed. It comes back by itself when what failed changes.
