## The pieces

| Sheet                | What                                                                      | Layer                       |
| -------------------- | ------------------------------------------------------------------------- | --------------------------- |
| `layers.css`         | the layer order; MUST be first in every tree scope                        | --                          |
| `reset.css`          | box-sizing / margin reset for shadow markup                               | `ui.reset`                  |
| `tokens.css`         | type, spacing, radii, borders, ink, shadows, motion, z-index, breakpoints | `ui.tokens`                 |
| `colors.css`         | palette, semantic and neutral colours, remaps, colour utilities           | `ui.tokens`, `ui.utilities` |
| `sizes.css`          | size ratios, size remaps, font-size and spacing utilities                 | `ui.tokens`, `ui.utilities` |
| `animations.css`     | the transition catalogue and its hooks                                    | `ui.utilities`              |
| `utilities.css`      | layout / text / theme / visibility utilities                              | `ui.utilities`              |
| `typography.css`     | page typography, opt-in with `class="ui-typography"`                      | `ui.base`                   |
| `native.css`         | native markup slotted into components, CSS-only tooltips, `ui-native`     | `ui.components`             |
| `themes/classic.css` | Fomantic's original look                                                  | `ui.theme`                  |
| `themes/dark.css`    | force the dark scheme page-wide                                           | `ui.theme`                  |
| `ui.css`             | one `@import` entry for pages without the runtime                         | --                          |

`tokens.css`, `colors.css` and `sizes.css` are generated from `styles.vocabulary.en.ts` (`yarn gen:styles`).

## Units

- NEVER `rem`: the host page can redefine it. The ONE absolute length is `--ui-font-size` (px, default `16px`);
  everything else is `em` of the local font size, or px for hairlines and shadows.
- A component root sets `font-size: calc(var(--ui-font-size) * var(--ui-scale, 1))` and uses `em` inside.
- Scale a whole region by overriding `--ui-font-size` on a wrapper; components inside follow.

## Layers

```css
@layer ui.reset, ui.tokens, ui.base, ui.components, ui.utilities, ui.theme, ui.app;
```

- Later layers win regardless of specificity; unlayered page CSS beats all of them.
- Each component adds `ui.components.<name>.types / content / variations / states`, so states beat variations
  without `!important`.
- `layers.css` must be adopted FIRST into the document and into every shadow root (each is its own scope).

- Declared on `:root`, plus a `:host` copy guarded by a style query, so components rendered without the page sheet
  still get defaults, while page and wrapper overrides inherit into components everywhere else.
- Colours are `light-dark()` token streams, resolved where they're USED, so `color-scheme` on any subtree flips
  every colour below it, in the page and through shadow boundaries.
- The per-scheme bases (`--ui-red-on-light`, `--ui-red-on-dark`) are registered with `@property`, so they animate.

### Colour tokens

For every hue (`red orange yellow olive green teal blue violet purple pink brown grey black`), the aliases
(`primary` => `blue`, `secondary` => `black`) and the semantic colours (`positive negative info warning`):

| Token                                             | Meaning                                                                 |
| ------------------------------------------------- | ----------------------------------------------------------------------- |
| `--ui-red`                                        | the colour, `light-dark(var(--ui-red-on-light), var(--ui-red-on-dark))` |
| `--ui-red-hover / -focus / -down / -active`       | states                                                                  |
| `--ui-red-text / -header / -border / -background` | roles, per scheme                                                       |
| `--ui-red-inverted`                               | the colour on dark surfaces, whatever the scheme                        |

## Remaps

Component CSS never names a hue. A colour class re-points the GENERIC tokens (`--ui-color`, `--ui-color-text` ...)
and one rule set consumes them. Sizes work the same way through `--ui-scale`.

```css
/* generated, colors.css */
.ui.red,
.ui-red {
  --ui-color: var(--ui-red);
  --ui-color-text: var(--ui-red-text);
  --ui-color-on: var(--ui-red-on); /* white or ink, picked for WCAG contrast when generated */
}

/* component CSS */
.ui.button {
  background: var(--ui-color, var(--_ui-button-background));
  color: var(--ui-color-on, inherit);
}
```

- Components READ `--ui-color*` with a fallback for the uncoloured look; they NEVER declare them.
- The generic tokens INHERIT: `<div class="ui-red">` recolours every component inside it.

## Component tokens

Every component has public tokens of its own, `--ui-<component>-*` (`--ui-button-radius`, `--ui-card-width`), listed
with their defaults on its page. Set them anywhere above or on the component:

```css
:root { --ui-button-radius: 0; }                               /* every button */
.toolbar { --ui-button-padding-inline: 0.75em; }                /* a region */
ui-button.cta::part(button) { --ui-button-background: gold; }   /* one kind, on its inner box */
ui-card { --ui-card-header-color: var(--ui-violet-text); }      /* the headers inside every card */
```

- They inherit into the shadow root, where the component reads each one through a private alias
  (`--_ui-button-radius: var(--ui-button-radius, var(--ui-radius))`), so nothing inside blocks them.
- A variation that swaps a value (`circular`) wins over the token; one derived from it (`compact` padding) follows it.
- Never set the `--_ui-*` names: they are the components' private plumbing.

## The app stylesheet

The page has at most ONE `<link>` or `<style>` with `id="ui-app-stylesheet"`. The runtime mirrors it into one
shared constructable sheet and appends it LAST to every component's `adoptedStyleSheets`, so its rules reach
component internals in Fomantic's class grammar:

```css
/* #ui-app-stylesheet */
@layer ui.app {
  .ui.primary.button {
    border-radius: var(--ui-radius-pill);
  }
  .ui.card > .content > .header {
    letter-spacing: 0.01em;
  }
}
```

This site's own stylesheet is its app stylesheet: every site rule is a `.site-*` class, so none of them match
inside a component by accident.

## Overriding colours

Globally, one base token re-colours the hue everywhere, derived states and roles included:

```css
@layer ui.app {
  :root {
    --ui-red-on-light: oklch(0.58 0.22 20);
    --ui-red-on-dark: oklch(0.72 0.17 20);
    --ui-primary: var(--ui-violet);
  }
}
```

Per region, override tokens on a wrapper; per instance, set the generic tokens on an uncoloured component:

```html
<section style="--ui-font-size: 18px; --ui-radius: 0">...</section>
<section class="ui-dark">...</section>
<ui-button style="--ui-color: hotpink; --ui-color-hover: deeppink; --ui-color-on: black">Hot</ui-button>
```

## Themes

A theme is a sheet of token overrides in `@layer ui.theme`, loaded after the foundation. Tokens inherit into
shadow roots, so components follow without adopting anything.

- `themes/classic.css`: Lato, 14px, Fomantic's size ratios and original palette, 4px radii, flat shadows. Try
  the **Classic** toggle in the header.
- `themes/dark.css`: `color-scheme: dark` on `:root`. The header's **Dark** does the same with `ui-dark`.

Dark mode follows the OS by default (`color-scheme: light dark` on `:root`). A light-only page sets
`:root { color-scheme: light }` or `class="ui-light"`.

## Build notes

- `@custom-media` and the `@import`s in the sheets need Lightning CSS (Vite's `css.transformer: "lightningcss"`
  with `drafts.customMedia`).
- `css.lightningcss.targets` MUST be modern browsers. With Vite's default targets Lightning CSS lowers
  `light-dark()` into variables substituted at `:root`, which breaks `ui-dark` subtrees.
