<Section title="While loading">
  `display` says what shows until every component inside is ready (or `timeout`, 5s by default, has passed):

  - `skeleton` (the default):  a `<ui-placeholder>` for each component that describes one, drawn in the root's own
    shadow DOM, so your page's DOM is never touched.  Placeholders stack in page order;  inline ones (buttons,
    labels, inputs) sit side by side.
  - `when-ready`:  nothing, with the space kept.
  - `immediately`:  everything as it arrives.

  `loading="..."` shows a `<ui-loader>` with that message instead (a bare `loading` says "Loading…").

</Section>

<Section title="Behaviour">
  - Loading:  each undefined `ui-*` tag inside (now, and whenever content is added) imports its component once per
    page.  Which component defines a tag comes from a generated catalog (`yarn gen:root` after adding a tag).
  - Ready:  every component imported, then every element inside ready (an inner root:  settled).  Then
    `:state(ready)`, `ui-ready` with `{ failed }`, and the content shows.  Content added later loads too, but is never
    hidden again.
  - Failures:  a tag no component defines (`unknown`), a component that can't be imported (`failed`), or one not
    ready by `timeout` (`timeout`) fires a cancelable `ui-error` (cancel it to skip the console warning) and is
    listed in `ui-ready`'s `failed`.  The content shows anyway;  a broken element shows its native fallback.
  - Without JavaScript (or before the root's script runs, with `@spell-app/ui/styles` loaded), an undefined root
    hides its content only under `@media (scripting: enabled)`:  server-rendered pages still show as sent.
  - Swap the loading look in code:  `UIRoot.Loading` (a `<ui-loader>`) and `UIRoot.Skeleton` (`<ui-placeholder>`s).

<Section title="Accessibility">
  - While loading, the content is hidden (`visibility: hidden` or not drawn), so assistive technology doesn't read
    half-built UI.  The placeholders are decorative (`aria-hidden`).
  - The `loading` message is a `<ui-loader>`:  `role="status"`, announced politely.
  - Without a box (no `width` / `height` / `fixed`) the root adds nothing to the page's structure:  headings and
    landmarks inside are the page's own.
</Section>
