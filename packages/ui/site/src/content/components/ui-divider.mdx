<Section title="Behaviour">
  `hidden` is Fomantic's word for the spacing-only divider.  Its JS property is `dividerHidden`, so it does not shadow
  `HTMLElement.hidden`.

  <VocabularyTable family="ui-divider" />
</Section>

<Section title="Theming">
  Theme with the public `--ui-divider-*` tokens:  set one on the element, on any ancestor (a region, `:root`), or on
  the inner box through `::part(divider)`.  They inherit into the shadow root, where the sheet reads each through a
  private alias, so nothing inside blocks them.  A `section` divider swaps in `--ui-divider-section-margin`, whatever
  the base margin.

```css
/* every divider on the page */
:root {
  --ui-divider-line-color: var(--ui-border-color-strong);
}
/* one region */
.sidebar {
  --ui-divider-margin: 0.5em;
}
```

  <CssTokens family="ui-divider" />
</Section>

<Section title="Accessibility">
  - A divider is `role="separator"`, not `<hr>`, because a horizontal or vertical divider carries text an `<hr>` can't hold.
  - A `vertical` divider adds `aria-orientation="vertical"`.
  - A `hidden` divider is `role="none"`:  it is spacing only and is not announced.
  - The `icon` is decorative.
  - Without JavaScript the native fallback renders the same `ui divider` element with its text;  only the `icon` shorthand is dropped.
</Section>
