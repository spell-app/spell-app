<Section title="Behaviour">
  A flyout is [`<ui-modal>`](../ui-modal/)'s element in a flyout's clothes:  the same `<dialog>` opened with
  `showModal()`, so focus moves inside, the rest of the page is inert and scroll-locked, Escape closes only the
  topmost overlay, and focus returns to whatever opened it.  Its dimmer is lighter than a modal's.  Loading the
  flyout family defines `<ui-modal>` too.

  Everything the modal does, it does:  open it with no script from a native `<button commandfor="id"
  command="--show">` (`--close` closes it), or write `open` from code (which fires no `ui-open` / `ui-close`).
  `closedby` says what dismisses it:  `any` (the default:  Escape or a click on the dimmer), `closerequest` (Escape
  only) or `none` (only its own buttons).  Buttons inside act by Fomantic's classes:  `approve` / `ok` / `positive`
  approve, `deny` / `cancel` / `negative` deny, each first dispatching the cancelable `ui-approve` / `ui-deny`.

  - `ui-open` (cancelable):  a user asked to open it, through an invoker command.
  - `ui-close` (cancelable):  about to close;  `detail.reason` is `escape`, `outside`, `close`, `approve`, `deny` or
    `close-all`.
  - `ui-show` / `ui-hide`:  shown or hidden, once the slide has finished.

```js
const help = document.querySelector("#help")
help.addEventListener("ui-approve", (event) => {
  if (!form.checkValidity()) event.preventDefault() // stay open
})
help.open = true // open from code:  no ui-open
```

<Section title="Theming">
Theme with the public `--ui-flyout-*` tokens:  set one on the element, on any ancestor (`:root` for every flyout), or
  on the box through `::part(flyout)`.  The `width` words and columns replace
  `--ui-flyout-width`;  `inverted` replaces the background, the header colour and the actions background.  Slotted
  parts read `--ui-flyout-header-color` and `--ui-flyout-actions-background` from the flyout, so set those on the
  flyout or above it, not on the part.  `--ui-flyout-dimmer-background` colours the backdrop;  `blurring` reads the
  shared [dimmer](../ui-dimmer/#theming) tokens.  The shorthands are parts:  `header`, `content`, and `close` for the
  close icon.

```css
ui-flyout {
  --ui-flyout-width: 480px;
  --ui-flyout-dimmer-background: oklch(0 0 0 / 0.25);
}
ui-flyout::part(close) {
  opacity: 1;
}
```

<Section title="Accessibility">
  - A real modal `<dialog>`:  focus moves inside and Tab stays there, the rest of the page is inert, and focus
    returns to the opener when it closes.
  - Named by the host's `aria-label`, else the `header` shorthand, else a slotted `<ui-header>`.  A flyout with
    neither (a cookie bar) needs `aria-label`.
  - The close icon is a real button named "Close" (translated), placed last so the first focus lands in the
    content.  Put `autofocus` on the control that should take focus first.
  - Escape closes it unless `closedby="none"`;  with `none`, make sure a button inside closes it.

  | Key               | Action                                                    |
  | ----------------- | --------------------------------------------------------- |
  | Tab / Shift + Tab | Move between the controls inside the flyout (never out)   |
  | Enter / Space     | Activate the focused button (approve, deny, close)        |
  | Escape            | Close it (`closedby` `any` or `closerequest`)             |

  - If the element fails to render, its native fallback is the modal's:  the same `<dialog>`, shown with
    `showModal()` while the host has `open`, so it still traps focus, dims the page and closes on Escape.  It drops
    invoker commands (open it by setting `open`), the `ui-open` / `ui-close` vetoes and the slide.
</Section>

<Section title="Framework usage">
  Bind `open` to your state and listen for `ui-close` (and `ui-approve` / `ui-deny`) to follow the user.

```jsx
// React 19
<ui-flyout open={open} position="right" header="Help" onui-close={() => setOpen(false)}>...</ui-flyout>
```

```html
<!-- Vue 3.5: compilerOptions.isCustomElement = (tag) => tag.startsWith("ui-") -->
<ui-flyout :open="open" position="right" header="Help" @ui-close="open = false">...</ui-flyout>
```

```jsx
// Solid 2:  no `on:` namespace, so add `ui-*` listeners in a ref callback
<ui-flyout prop:open={open()} position="right" header="Help" ref={(el) => el.addEventListener("ui-close", () => setOpen(false))}>
  ...
</ui-flyout>
```

</Section>
