A placeholder is used to reserve space for content that soon will appear in a layout.

Placeholders can include <ui-placeholder-paragraph>, <ui-placeholder-header> (image for an image header) and <ui-placeholder-image> to let you format the placeholder to emulate the content being loaded. Not ported: Fomantic's "Simulate Loading" button, which swaps the skeleton for a loaded card -- a page script, not part of the placeholder. Replace the placeholder with the real content when it arrives. Add Delete Add Delete Add Delete

A placeholder can contain lines of text.

By default, repeated lines appear varied in width. It may be useful to give an exact length to make them match up with the content more closely.

A placeholder can contain a header.

Header lines are slightly taller than paragraph lines.

A placeholder can contain a paragraph.

Paragraphs are used to group lines together. Using square (1:1) or rectangular (4:3) embeds an aspect ratio into the image placeholder, so it keeps its shape in responsive layouts. Edit a value below to try it.
