<Section title="Behaviour">
  `<ui-breadcrumb>` is a `<nav>` around an ordered list;  each `<ui-breadcrumb-section>` is one item of it.  A section
  with `href` is a link (`target` works too);  an `active` section is the current page and never a link.  Each section
  draws its own divider before it, so there is nothing to put between them.  Breadcrumbs have no events.

  <VocabularyTable family="breadcrumb" />
</Section>

<Section title="Theming">
  Theme with the public `--ui-breadcrumb-*` tokens:  set one on the element, on any ancestor (a header, `:root`), or
  on the breadcrumb's box through `::part(breadcrumb)`.  The sections inherit them from the breadcrumb, so set them
  there or above, not on a section.  The text divider is the `--ui-breadcrumb-divider` token (a CSS string), so a
  whole site can change it once instead of setting `divider` on every breadcrumb;  a `divider` attribute still wins.

```css
header ui-breadcrumb {
  --ui-breadcrumb-divider: "»";
  --ui-breadcrumb-divider-color: var(--ui-primary);
  --ui-breadcrumb-active-font-weight: normal;
}
```

<Section title="Accessibility">
  - The WAI-ARIA breadcrumb pattern:  a `<nav>` landmark around an `<ol>`, whose items are the sections.
  - The landmark is named "Breadcrumb" (translatable);  an `aria-label` on the host replaces it.  Give each breadcrumb
    on a page its own name.
  - The `active` section carries `aria-current="page"`.  Linked sections are real `<a>`s:  focusable, with Enter to
    follow.
  - Dividers are drawn by CSS and hidden from assistive technology, so the list reads as its section names only.
  - Without JavaScript the native fallback renders the same `<nav>`, list, links and text dividers.  It drops
    `divider-icon` (the text divider shows instead), and the "Breadcrumb" name stays English.
</Section>
