ThingExplorer The things a running program has made, live, with their properties and actions.

The "Thing Explorer" tab of a runner's debug pane: every thing the running program has made, as a tree on the left, and the picked thing's properties and actions on the right. It changes as the program runs, so you can watch a todo get done, or a card move.

Written for: anyone changing the runners' debug pane, or reading its code Live: a real <spell-app>, its debug pane opened on this tab

The todos example, its debug pane open on "Thing Explorer": the pane under the app IS this component. Click a thing to see its details, then add a todo, or tick one, and watch the tree and the details change.

Live, from /element/spell.pack.js (yarn build:element in packages/app), which this set's pages load.

Each runner draws one in its debug pane, on the program's own copy of the spell runtime, once it's loaded:

SpellAppRunner.tsx · the Thing Explorer tab · 15 lines
  • things is the list of things the running program made, from ITS copy of the runtime, never the page's own: each <spell-app> on a page has its own things.
  • The tree shows the program's top-level things first, then all of them: in the order they were made, under the heading whose code made them, or grouped by type. The buttons in its header switch.
  • Properties and actions read in spell's words, like draw (a todos-app), when the project's words file is there; else by name.
  • An action that takes nothing has a play button, to do it now.
  • It's live, piece by piece: a changed property redraws just its own value, and a new thing adds just its row.
  • state and onStateChange keep what's picked and open, so it comes back after a restart.
  • Its tree's rows are TreeRows, and its headings SectionMarkers, shared with the TypeExplorer.
