Input An input is a field used to elicit a response from a user.

<ui-textarea> has its own page: Textarea.

A file input: type="file".

For a trigger button with your own text or an icon, use a File Action input.

A <ui-textarea> allows extended user input. Its states, variations and the rest are on the Textarea page.

Not ported: Fomantic's focus class, which draws the focused look on an unfocused input -- the look follows real focus (:focus-visible), so click or tab into any field.

An icon input field can show that it is currently loading data.

Loading inputs automatically turn their icon into a spinner while loading.

Input types with built-in validation (date, email, url ...) and required fields get the error look by themselves when invalid -- once the user has interacted with them, as :user-invalid does, so an untouched empty field never shows it.

An input can be formatted with an icon: icon, at the end by default.
