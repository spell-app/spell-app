<Section title="Fomantic's names">
  A page that was written for [Fomantic's emoji list](https://fomantic-ui.com/elements/emoji.html) can keep its names:
  a `<ui-root emoji="fomantic">` around them switches every emoji inside to them (`thumbsup`, `smile`, `flag_us`,
  `one` for the keycap, the shortcodes Discord and JoyPixels use), with FOMANTIC's meanings:  `dog` is the dog's face
  there, the whole dog in CLDR.  The two sets are never mixed inside a root, so the CLDR names stop working there.
  Emoji inside redraw when the root's `emoji` changes.  A page with no root switches page-wide from JS with
  `EmojiData.use("fomantic")`.

  <Example title="Fomantic's names" description="A root sets the name set for its subtree only.  `display=&quot;immediately&quot;` draws the content as it arrives.">
    <ui-root emoji="fomantic" display="immediately"><p><ui-emoji name="smile"></ui-emoji> <ui-emoji name="thumbsup"></ui-emoji> <ui-emoji name="flag_us"></ui-emoji> <ui-emoji name="dog"></ui-emoji></p></ui-root>
  </Example>

  A switch affects LATER lookups only:  an emoji already drawn keeps its glyph, so put the element at the top of the
  page (the page reads the last one it finds at its first lookup).  From JavaScript, `EmojiData.use("fomantic")`
  does the same.
</Section>

<Section title="Behaviour">
  An emoji is the real Unicode character drawn by the reader's own emoji font, never an image:  there is no image
  download and no per-emoji CSS, and it looks like the other emoji on their system.

  `name` takes an emoji's CLDR shortcode, Unicode's own name for it (`thumbs_up`, `grinning_face_with_smiling_eyes`,
  `flag_united_states`, `rocket`).  A name is case-blind, may keep its `:colons:`, and its words may be joined any
  way:  `thumbs_up`, `thumbs up`, `thumbs-up`, `thumbsUp` (handy from JS), `thumbsup`.  An unknown name draws nothing.
  These are the page's default NAME SET, `cldr`;  [Fomantic's names](#fomantics-names) are another, and a page uses
  one set at a time.

  The names load in small pieces, one per first letter, the first time a name starting with that letter is used;
  later emoji from the same piece draw at once.  `EmojiData`, exported with the element, picks the name set, preloads
  a name or adds your own:

```js
import { EmojiData } from "@spell-app/ui/ui-emoji"

EmojiData.use("fomantic") // later lookups use Fomantic's names;  "cldr" is the default
EmojiData.register("approve", "👍") // <ui-emoji name="approve"> now draws 👍, in either set
await EmojiData.get("tada") // loads the "t" names;  resolves to "🎉"
```

<Section title="Theming">
  Theme with the public `--ui-emoji-*` tokens:  set one on the element, on any ancestor (a region, `:root`), or on
  the emoji's box through `::part(emoji)`.  They inherit into the shadow root, where the sheet reads each through a
  private alias, so nothing inside blocks them.  `--ui-emoji-font-family` picks the emoji font;  the
  `--ui-emoji-size-small` / `-large` / `-big` tokens are the size ratios.  Class-grammar `medium` is Fomantic's 3em
  emoji (fixed, not a token):  the element treats `medium` as the default size.

```css
/* every emoji on the page */
:root {
  --ui-emoji-font-family: "Noto Color Emoji", sans-serif;
}
/* one region */
.reactions {
  --ui-emoji-size-large: 4;
}
```

<Section title="Accessibility">
  - By default the emoji is plain text, so assistive technology reads the character's own Unicode name in the
    reader's language ("grinning face with smiling eyes").
  - `label="..."` makes it a `role="img"` named by the label:  use it when the emoji stands for something else, as
    "Approved" does in the example.
  - An empty `label` marks it decorative (`aria-hidden`), for an emoji that only repeats nearby text.
  - An unknown name renders an empty box with no role, so nothing is announced.
  - `link` is only a look:  the emoji takes no focus and does nothing on click.  Put it inside a `<button>` or `<a>`
    and give that control a name.
  - `loading` spins the glyph, and stands still under reduced motion;  `disabled` only dims it.
  - If the emoji can't render, its native fallback draws the same character with the same naming rules.  It reads
    `name` and `label` once, so later changes to them are not shown.
</Section>
