Q7 Rulex: how to say "space required" (and adjacency beyond Symbols)? → D17

Markdown needs "space required": - item is a list item, -item is text; # Title a heading, #Title text. With D13, symbol runs (**, ]() no longer allow spaces, but nothing can REQUIRE one.

Whitespace is already kept: with today's WhitespacePolicy.LEADING_ONLY, each token carries the spaces after it in token.whitespace. So a new policy wouldn't help by itself: the gap is that rulex has no way to SAY it.

A. \s marker (recommended)

Regex's \s: "whitespace here". Checks the previous token's whitespace; consumes nothing. 

\-\s{text}
\#{1,6}\s{text}

No new policy. Spell untouched (no syntax uses it). Small: one zero-width rule.

B. New WhitespacePolicy

Keep inline whitespace as tokens; rulex's \s matches one; a Sequence skips whitespace the syntax doesn't mention.

Same syntax as A, but every rule class must step over whitespace tokens: much bigger change to parser.

C. Write it as it looks

Syntax spacing is significant: no space in the syntax = none allowed; a space = allowed; \s = required. 

![{alt}]({url})   adjacent
- \s{text}

Most natural for markdown; changes spell wherever a syntax has no space but input does (e.g. {a}'s).

What C changes in spell (packages/docs/rulex/experiments/adjacency-impact.mts): 11 of 135 syntaxes have parts written touching. Each keeps today's behaviour by adding a space to the syntax.

Q9 Spacing as written: how do a repeat's copies space? → D24

Found designing P2.3. The rulex doc said a repeat's copies follow the spacing written after the repeated part (-{3,} = only ---). Applied to everything, that breaks 2 spell syntaxes whose repeats are written touching: {rhsChain:expression_suffix}+ (expressions.ts:432) and ({method_keyword}|\({method_arg}\))+ (methods.ts:842: to move (a card) to (a pile)).

Markdown needs both: #{1,6} and `{3,} touching, - - - spaced.

option rule spell markdown
A. Symbols run (recommended) A repeated SYMBOL is a run, like **: copies touch, unless a space before the flag (- {3,}). Any other repeat (subrule, group, keyword) spaces freely, as today unchanged #{1,6}\s{text}, `{3,}, (- {3,}|\* {3,}|_ {3,})
B. As written, everywhere Copies touch unless a space before the flag, whatever is repeated 2 syntaxes get a space: {rhsChain:expression_suffix} + same as A
C. Repeats always free Spacing as written applies between parts only unchanged # # would read as level 2; touching runs need a custom rule
D24 A: a repeated SYMBOL's copies touch unless a space before the flag; other repeats space freely. {space} / {spaces} replace \s (Q9)

Owen: "A, but have {space} rule which means single space character, and {spaces} which means any amount of spaces rather than \s".

  • {space}: exactly one space between the tokens either side
  • {spaces}: one or more spaces / tabs (read "any amount" as at least one: {spaces}? = allowed, which a written space already says)
  • both own their boundary: the syntax's spacing around them doesn't apply
  • examples: #{1,6}{spaces}{text}, (-|\*|\+){spaces}{text}, \[{space}\] (unchecked task box)
