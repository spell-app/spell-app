2. What changed

One commit per phase on the branch (P3 and P4 share one: their docs edits interleave).

Re-establish (52ba1e85)
  • yarn test:hmr: Vite 8 resolves tsconfig aliases only for TS / JS importers; the HMR plugin injected $/ui/elements/HotDefinitions into ?inline sheets. Now injected by file path.
  • yarn site:build: Astro 7's prerender bundle resolved cookie to express's hoisted 0.7.1. Bundled in its prerender environment.
  • A visual test changed every day: WebKit draws an empty date field from the system clock. Masked.
  • Root CI runs neither check, so both broke silently in the move.

Icons (fec460c5)
  • UI.icons.get() / use() / ready never reject: a pack with no usable URL (malformed, or a built-in pack in an IIFE bundle) is a failed pack, warned once.
  • IconGlyph.load() catches: no unhandled rejection per icon.
  • The pack builder is importable from any package: $/ui/tools/IconPackBuilder.

Bug sweep and decisions (2fe17423)
  • Behaviour: toast pauses only after a real pointer move; render-effect errors reach the fallback; read-only radios; search reactivity and ::part(search).
  • Layout: calendar width; dropdown menus position: fixed (WebKit flipped every menu below the first screen); card links; items margins; images in lists; tables stack by viewport again.
  • Tokens: inverted segment groups; lone feed events / comments; CSS tooltips; private switches.
  • Decisions built: modal closable + closedby; invoker commands on <ui-button>; popup hoverable; CLDR emoji names; label colour like Fomantic; sidebar / flyout width words and columns; container breakpoint tokens; 8 kB budget.

Release chores (04146653)
  • yarn test:all: 92 failures to 4. Real Firefox / WebKit bugs fixed (dialog focus through slots, list widths, stale labels, rating wrap, replaceSync, grid container queries); tests made browser-neutral (Keys.tab(), tolerances, support-flag skips).
  • Kitchen sink page; CHANGELOG.md; publish dry run.

3. Why
  • Match Fomantic where a call wasn't made: card links, table stacking, label colour.
  • Toast pause needs a real move: a toast appearing under a resting pointer never left (Fomantic pauses on plain enter; a deliberate difference).
  • Fomantic wins emoji name clashes (19 names): existing pages keep their picture.
  • Unnamed grid / items container queries: WebKit scopes container names to the tree, so a slotted column couldn't see the host's name.
  • Test files run one at a time under UI_TEST_ALL: a browser runs them in iframes of one page with one focus; Firefox and WebKit hand it to the last iframe that asked.
  • Budget 8 kB per family (Owen): 7.3 kB average is a full port of Fomantic's variations.

4. Limits
  • Visual baselines are macOS only: Docker Desktop 4.42.1 crashes on macOS 26.6, so no Linux set.
  • A plain class-grammar .ui.label still takes a coloured ancestor's colour (elements don't).
  • Grid / card group hosts keep the margin gap items had; a raw slotted <img> in a list item still wraps (use <ui-image> or image).
  • The open-from-start dropdown example opens upward in its screenshot (its anchor is below the capture viewport): correct, but it covers two small sections.
  • Emoji names data grew ~35% (a page still loads one ~5 kB chunk).
  • Popup, dropdown menu and toast don't answer invoker command events yet.
  • The rest: SUSPECTED-BUGS.md (## ui) and packages/ui/docs/status.md.
